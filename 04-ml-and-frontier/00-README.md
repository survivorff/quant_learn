# 04 · 机器学习与前沿

> 这一章讲"现在最前沿的量化在用什么"。但先说结论，避免走弯路：
>
> **2026 年的现实是：ML 在量化里的胜利不是"更强的预测模型"，而是"更好的研究方法论 + 更好的特征工程 + 把 ML 用在对的环节"。**

---

## 一、先破除三个幻觉

### 幻觉 1："用深度学习预测价格"

价格预测的信噪比极低（日频上有信息的部分可能只占方差的百分之几）。在这种数据上，模型容量越大越容易拟合噪声。

**实际情况**：在表格化的因子数据上，**梯度提升树（LightGBM/XGBoost）仍然是主力**，深度学习没有稳定的优势。深度学习真正有价值的地方是：非结构化数据（文本、订单簿序列）、多任务学习、以及需要端到端优化的执行问题。

### 幻觉 2："问 LLM 该买还是该卖"

多项测试显示，直接让 LLM 根据新闻或价格历史做买卖决策，通常打不过简单的动量或均值回归基线（[相关综述](https://gaper.io/can-llms-crack-algorithmic-trading-code)，内容已改写以符合许可要求）。

**2026 年的实际共识**：经典量化信号 + LLM 作为辅助工具，才是有效的组合。LLM 的位置是研究助手、文本信号提取、代码生成、因子挖掘的搜索助手，**不是决策者**。

### 幻觉 3："模型是核心竞争力"

在金融 ML 里，**标签构造、样本权重、验证方法的重要性远超模型选择**。

López de Prado 的核心贡献不是提出新模型，而是指出：金融数据非 IID、标签重叠、需要 purging、需要三重障碍法。**方法论 > 模型。**

## 三、2026 年的技术现状（我的判断）

| 方向 | 成熟度 | 我的判断 |
|---|---|---|
| 梯度提升树做因子合成 | 成熟 | ✅ **先做这个**，性价比最高 |
| AFML 方法论（三重障碍/CPCV/样本权重） | 成熟 | ✅ **必学**，比模型重要 |
| 元标注（meta-labeling） | 成熟 | ✅ 很实用：主模型定方向，二级模型定下注 |
| 深度学习做序列预测 | 中等 | ⚠️ 有条件用（需要高频数据和大样本） |
| 订单簿深度学习（DeepLOB 类） | 中等 | ⚠️ 需要 L2 数据和算力，后期考虑 |
| RL 做执行优化 | 中等 | ⚠️ 有价值但工程复杂 |
| RL 做方向决策 | 不成熟 | ❌ 样本效率低、过拟合严重 |
| LLM 做文本/新闻信号 | 成熟 | ✅ 可做，crypto 社媒数据丰富 |
| LLM 辅助因子挖掘（Alpha-GPT 类） | 快速发展 | ✅ **我的优势区**（AI 工程化经验） |
| LLM Agent 自动化研究流水线 | 快速发展 | ✅ **我的优势区** |
| LLM 直接做交易决策 | 不成熟 | ❌ 见幻觉 2 |
| 生成模型做合成数据 | 探索中 | ⚠️ 有前景（缓解样本不足），但要小心分布失真 |

### 关于 LLM 辅助因子挖掘

这个方向（如 Alpha-GPT 类框架）在 2024-2026 有明显进展：用 LLM 理解研究者的直觉描述，生成候选因子表达式，再用回测系统筛选。相关工作在 WorldQuant 量化竞赛中取得了不错的成绩（[相关分析](https://systematicstandard.substack.com/p/the-alpha-gpt-revolution-how-wall)，内容已改写以符合许可要求）。

**为什么这是我的机会**：
- 它本质上是"LLM + 搜索 + 验证流水线"的工程问题
- 我有 Agent/LLM 工程落地经验
- 我有（正在建的）回测验证流水线
- 纯数学背景的人做这个反而不顺手

**但要清醒**：LLM 生成候选只是加速了"提出假设"，验证的严谨性要求不变。生成 1000 个因子然后挑最好的 = 极端的多重检验问题。**必须配 DSR/PBO 修正，否则这个方向就是自动化的自欺。**

## 四、出口标准

1. 为什么金融 ML 不能用标准的 K-fold 交叉验证？purging 和 embargo 解决什么问题？
2. 三重障碍法构造标签，比"未来 N 期收益的符号"好在哪？
3. 元标注是什么，为什么它能提升夏普而不改变方向预测能力？
4. 为什么重叠标签需要样本权重？唯一性（uniqueness）怎么算？
5. MDI 特征重要性有什么问题？为什么要用 MDA 或 SHAP？
6. 你的 ML 模型样本内 IC 0.08、样本外 0.02，可能的原因有哪几类？
7. RL 在量化里最靠谱的应用是什么？为什么不是方向预测？
8. LLM 在你的研究流程里应该出现在哪几个环节？哪些环节绝对不该用？

## 六、一条贯穿本章的纪律

> **ML 让你能更快地过拟合。**
>
> 每增加一个模型自由度，你就需要更严格的验证。所以：先把 [`03-research-infra`](../03-research-infra/) 的验证流水线建好，再上 ML。
>
> 顺序颠倒的人，会用最先进的工具得出最糟的结论。
