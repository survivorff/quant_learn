# 01 · 金融机器学习的特殊性

> 这一章的内容基本来自 López de Prado 的 AFML。**它是我认为投入产出比最高的一本量化书**，因为它解决的是方法论问题，而方法论错了，模型再好也没用。
>
> 核心命题：**把 sklearn 的标准流程直接套用到金融数据上，几乎必然得到错误结论。**

---

## 一、金融数据为什么特殊

| 特性 | 标准 ML 假设 | 金融现实 | 后果 |
|---|---|---|---|
| 独立性 | 样本 IID | 强序列相关，标签重叠 | 交叉验证泄漏，模型评估虚高 |
| 信噪比 | 较高 | **极低** | 容易拟合噪声 |
| 平稳性 | 分布固定 | 制度变化、结构断裂 | 训练分布 ≠ 预测分布 |
| 样本量 | 可以很大 | 有效样本量小（受独立性限制） | 高方差估计 |
| 标签 | 明确给定 | **需要自己构造，构造方式决定一切** | 标签设计错了全盘错 |
| 类别平衡 | 常近似平衡 | 有信息的事件稀少 | 需要采样与权重处理 |
| 对抗性 | 无 | **有**：你的行为会改变市场 | 回测的收益在实盘会衰减 |
| 特征稳定性 | 固定 | 因子会衰减、失效 | 需要持续监控 |

**最重要的一条是"对抗性"**：这是金融 ML 与图像识别的根本区别。猫的图片不会因为你识别了它就变成狗，但一个 alpha 被交易之后就会衰减。

## 二、标签构造（最关键的一步）

### 朴素做法的问题

```python
label = sign(price[t+N] / price[t] - 1)   # 未来 N 期收益的符号
```

问题：
1. **忽略了路径**：期间可能先跌 20% 再涨回来。实盘上你早就止损了
2. **固定时间窗**：没有考虑波动率差异（低波动期的 1% 和高波动期的 1% 意义不同）
3. **没有区分"有意义的变动"和噪声**：0.01% 的涨幅被标为正类

### 三重障碍法（triple-barrier method）

对每个样本设三个障碍，看**哪个先被触及**：

```
        ┌──────────── 上障碍（止盈）→ 标签 +1
        │
起点 ───┼──────────────────────────┤ 垂直障碍（时间到）→ 标签 0 或按收益符号
        │
        └──────────── 下障碍（止损）→ 标签 -1
```

关键设计：
- **上下障碍按波动率缩放**（如 2 倍当期预测波动率），而不是固定百分比
- 垂直障碍是最大持仓时间
- 标签反映了"如果我按这个规则交易，结果会怎样"

**为什么这更好**：标签直接对应了一个可执行的交易规则（含止盈止损），而不是一个抽象的"未来收益"。**训练目标与实际交易目标对齐了。**

### 事件驱动采样（不是每个 bar 都要预测）

大部分时间市场没有可交易的信息。对每个 bar 都做预测 = 大量无信息样本稀释了模型。

做法：先用一个过滤器选出"值得预测的时刻"，只对这些时刻构造标签。

| 过滤器 | 逻辑 |
|---|---|
| CUSUM 过滤器 | 累积偏离超过阈值才触发（AFML 推荐） |
| 波动率突破 | 波动率超过分位数 |
| 结构性事件 | 强平、大额成交、资金费极值 |
| 你自己的初级信号 | 见"元标注" |

**这一步能显著提升信噪比**，也大幅减少计算量。

### 信息驱动的 bar（不用时间等分）

时间等分的 bar 有个问题：不同时段的信息量差别巨大。

| bar 类型 | 采样规则 |
|---|---|
| Time bar | 固定时间（最常用，但统计性质最差） |
| Tick bar | 固定成交笔数 |
| Volume bar | 固定成交量 |
| **Dollar bar** | 固定成交金额 —— **统计性质最好**（收益率分布更接近正态，序列相关更弱） |
| Imbalance bar | 订单流失衡累积到阈值 |
| Run bar | 连续同向成交累积到阈值 |

**Dollar bar 是 AFML 的推荐默认选择。** 对 crypto 尤其适用，因为价格量级变化大（BTC 从几千到几万，固定 volume bar 的信息量不可比）。

## 三、样本权重（重叠标签的必需处理）

### 问题

如果标签是"未来 5 天的结果"，那第 1 天和第 3 天的标签共享了 3 天的价格信息。它们不是独立样本。

直接训练 = 模型以为自己有 N 个独立样本，实际远少于 N。结果是过度自信、过拟合。

### 唯一性（uniqueness）

```
1. 对每个时刻，统计有多少个标签的区间覆盖它 → 并发度 c_t
2. 每个样本的平均唯一性 = 该样本区间内 1/c_t 的平均值
3. 样本权重 ∝ 平均唯一性
```

直觉：重叠越多的样本，信息越冗余，权重越低。

### 时间衰减权重

更近的数据更相关（市场会变）。给旧样本降权。

但注意：衰减太快 = 有效样本量骤减 = 方差上升。需要权衡。

### 顺序自举（sequential bootstrap）

标准 bagging 的随机采样会因为重叠而产生高度相似的子样本。顺序自举在采样时考虑唯一性，让子样本更独立。

**实践价值**：配合随机森林/bagging 使用，提升集成的有效性。

## 四、元标注（meta-labeling）—— 很实用的技巧

### 结构

```
主模型（primary model）：决定方向（买/卖）
      ↓
二级模型（meta model）：决定"这个信号该不该交易、下多大注"
```

二级模型是一个**二分类**问题：预测主模型的这次信号是否会盈利。

### 为什么有效

1. **分离关注点**：方向预测和下注大小是两个不同的问题，混在一起学效果差
2. **提升精确率**：主模型可以设计成高召回（宁可多发信号），二级模型负责过滤，提升精确率
3. **可以用任何主模型**：主模型可以是你的经典策略（如趋势跟踪），二级模型是 ML —— **这是把 ML 加到现有策略上的最优雅方式**
4. **二级模型的问题信噪比更高**：判断"这次信号靠不靠谱"比"价格往哪走"容易

### 对我的实际意义

**这是我用 ML 的首选切入点**：

```
主模型 = 我的 EWMAC 趋势策略（经济逻辑清晰、可解释）
二级模型 = LightGBM，输入：波动率状态、资金费、OI、市场宽度、微观结构特征
输出 = 这次趋势信号的胜率预测 → 映射到仓位
```

好处：保留了策略的可解释性和经济逻辑，同时用 ML 提升了执行质量。比"端到端让 ML 决定买卖"稳健得多。

## 五、模型选择

### 为什么树模型仍是主力

| 优势 | 说明 |
|---|---|
| 处理表格数据强 | 因子数据天然是表格 |
| 不需要特征缩放 | 省一堆预处理 |
| 自动捕捉非线性和交互 | |
| 对异常值相对稳健 | 金融数据异常值多 |
| 可解释性尚可 | 特征重要性、SHAP |
| 样本效率高 | 金融数据样本量有限 |
| 训练快 | 能做大量实验 |

| 模型 | 特点 |
|---|---|
| LightGBM | 快，默认选择 |
| XGBoost | 成熟稳定 |
| CatBoost | 类别特征处理好 |
| 随机森林 + 顺序自举 | AFML 推荐（bagging 对过拟合更稳健） |
| 线性/Ridge/Lasso | **基线，必须做** —— 打不过线性模型的复杂模型没有价值 |

### 正则化的重要性

金融 ML 里正则化不是"可选优化"，是必需：
- 限制树深度（3-6 层通常够）
- 增大 min_child_samples
- 用 subsample 和 colsample
- 早停（用正确的验证集）
- 特征数量控制（不要塞 500 个特征）

**经验法则：如果你的模型需要 100+ 特征才 work，那它大概在拟合噪声。**

## 六、特征重要性（别用 MDI）

| 方法 | 原理 | 问题 |
|---|---|---|
| MDI（树的分裂增益） | 训练时统计 | **有偏**：偏向高基数特征；只反映样本内；相关特征互相稀释 |
| **MDA（置换重要性）** | 打乱某特征看性能下降 | 样本外评估，更可靠。**推荐** |
| **SHAP** | 博弈论的贡献分解 | 一致性好，能看方向和交互。**推荐** |
| 聚类特征重要性 | 先对相关特征聚类再评估 | 解决相关特征稀释问题（AFML 提出） |

**注意**：相关特征会互相"偷走"重要性。如果你有 10 个高度相关的动量特征，每个的重要性都会被低估。先聚类再评估。

## 七、诊断：样本外衰减的原因分类

模型样本内好、样本外差，可能的原因（按概率排序）：

| 原因 | 检测方法 |
|---|---|
| 1. 信息泄漏（未来函数） | 异常值注入测试；审计所有全样本操作 |
| 2. 验证方法有泄漏（没做 purging） | 用 CPCV 重跑对比 |
| 3. 过拟合（模型太复杂/试验太多） | 降低复杂度看衰减是否减少；算 PBO |
| 4. 制度变化 | 分时段评估；看衰减是渐进还是突变 |
| 5. 标签构造有问题 | 换标签方式对比 |
| 6. 特征在样本外不可得或分布漂移 | 对比训练/测试期的特征分布 |
| 7. 样本量不足 | 学习曲线：增加数据量看是否改善 |
| 8. 真实 alpha 就是很小 | 这是常态，接受它 |

**顺序很重要：先排除 1、2、3（自己的错），再考虑 4-8（市场的原因）。** 大多数人跳过前三个，直接归因于"市场变了"。
