# 01 · 概率、统计与假设检验

> 量化里 90% 的自欺欺人，源头都在这一章的三个概念：**分布假设、多重检验、样本量。**

---

## 一、收益率：先把最基础的搞对

### 简单收益率 vs 对数收益率

```
简单收益率  r_t = (P_t - P_{t-1}) / P_{t-1}
对数收益率  R_t = ln(P_t / P_{t-1}) = ln(1 + r_t)
```

| | 可加性 | 组合可加性 | 用在哪 |
|---|---|---|---|
| 简单收益率 | ❌ 跨时间不可加 | ✅ 组合收益 = 权重加权和 | 组合层面、计算实际 PnL |
| 对数收益率 | ✅ 跨时间可加 | ❌ 组合不可简单加权 | 时间序列建模、波动率计算 |

**实务口径**：单标的时间序列建模用对数收益；组合层面算 PnL 用简单收益。混用是常见 bug 来源。

小幅波动下 `ln(1+r) ≈ r`，但 crypto 单日 ±20% 很常见，这时近似误差不可忽略（r=0.2 时 ln(1.2)=0.182，差 9%）。

### 波动率损耗（volatility drag）

几何平均收益 ≈ 算术平均收益 − σ²/2。

含义：**波动本身吃掉收益**。两个策略算术均值相同，波动大的那个长期财富更低。这是为什么"降波动"本身就是 alpha，也是 Kelly 公式的直觉来源。

一个反直觉的例子：+50% 然后 −50%，算术均值是 0，但你亏了 25%。

### 年化的隐含假设

```
年化收益率  ≈ 均值 × N
年化波动率  ≈ σ × √N          # N = 一年的周期数
年化夏普    ≈ (均值/σ) × √N
```

`√N` 缩放成立的前提是**收益率独立同分布（IID）**。现实中：

- 存在自相关（趋势/动量）→ 长期波动被**低估**
- 存在均值回归 → 长期波动被**高估**
- 波动率聚集（GARCH 效应）→ 单一 σ 不能描述

**Crypto 用 365 而不是 252**（24/7 交易，无休市）。用错会让夏普虚高约 20%。

## 二、金融数据的分布：正态假设是最贵的错误

### 实证特征（stylized facts）

任何资产收益率序列都会呈现这些性质，crypto 尤其极端：

| 特征 | 表现 | 后果 |
|---|---|---|
| 厚尾（fat tails） | 峰度远大于 3 | 极端行情频率比正态预测高几个数量级 |
| 负偏（equity）/ 双向极端（crypto） | 偏度 ≠ 0 | 下跌更急，止损容易被跳空穿透 |
| 波动率聚集 | 大波动跟着大波动 | 风险有记忆，可预测 |
| 杠杆效应 | 跌时波动更大 | 相关性在危机中趋于 1 |
| 收益率近似无自相关，但**平方收益**强自相关 | 方向难预测，波动好预测 | 波动率策略比方向策略更靠谱 |
| 聚合高斯性 | 周期越长越接近正态 | 低频策略的正态假设相对安全 |

**实践含义**：
- 别用正态 VaR。用历史模拟法、EVT（极值理论），或者干脆用"最大历史回撤 × 1.5"这种粗暴但保守的估计
- 8 倍标准差事件在正态假设下是"宇宙年龄级"的罕见，在 crypto 里是"每年几次"

### 该记住的分布

| 分布 | 用途 |
|---|---|
| 正态 | 基准参照，别当真 |
| Student-t | 建厚尾，自由度 ν 控制尾部厚度（金融数据常见 ν ∈ [3,6]） |
| 幂律 / Pareto | 尾部行为、极端事件建模 |
| 对数正态 | 价格水平（几何布朗运动的解） |
| 混合正态 | 建"平静期 + 危机期"两状态 |

## 三、假设检验：从"看起来有效"到"统计上站得住"

### 基础工具箱

| 检验 | 问什么 |
|---|---|
| t 检验 | 收益均值是否显著不为 0 |
| Jarque-Bera / Shapiro | 是否正态（金融数据基本都拒绝） |
| Ljung-Box | 序列是否有自相关 |
| ADF / KPSS | 是否平稳（见下一章） |
| Engle ARCH-LM | 是否有异方差（波动率聚集） |
| Diebold-Mariano | 两个预测模型谁更好 |

### 关键：p 值不是"策略有效的概率"

p 值 = 在"策略无效"假设下，观察到当前或更极端结果的概率。它**不是**"策略有效的概率"。

### 多重检验：量化里最致命的统计陷阱

如果你在 α=0.05 下测试 N 个互相独立的无效策略，**预期会有 0.05×N 个"显著"结果**。

- 测 20 个 → 期望 1 个假阳性
- 测 500 个（一次参数网格扫描的常规规模）→ 期望 25 个假阳性

而你只会保留最好的那个，然后以为找到了 alpha。这就是回测过拟合的数学本质。

**修正手段**：

| 方法 | 思路 | 备注 |
|---|---|---|
| Bonferroni | α / N | 极保守，N 大时几乎测不出东西 |
| Benjamini-Hochberg (FDR) | 控制假发现比例 | 实务中更可用 |
| Deflated Sharpe Ratio (DSR) | 对试验次数与非正态性惩罚夏普 | López de Prado 提出，量化专用，**建议默认使用** |
| PBO（过拟合概率） | 用 CSCV 估计"样本内最优在样本外垫底"的概率 | 直接量化过拟合风险 |

**纪律要求**：在 `journal/` 里**记录你试过的所有参数组合和策略变体的数量**。不记录，就无法做 DSR 修正，也就无法判断结果可信度。这是最容易偷懒、也最致命的一步。

### 样本量：你以为的 5 年数据其实很短

估计一个真实夏普为 1.0 的策略、要在 95% 置信度下确认它显著不为 0，大约需要 **4 年**日频数据。夏普 0.5 需要约 16 年。

推论：
- 低频策略（日线以上）天然缺样本，容易过拟合
- 高频策略样本量大，统计上更容易验证 —— 但工程门槛和成本更高
- **样本量不足时，宁可信经济逻辑，不信统计显著性**

有效样本量还要考虑**独立性**：重叠标签、自相关会让"1000 个样本"的有效信息量远小于 1000。

## 四、相关性：三个必须知道的坑

1. **相关性 ≠ 因果**。老套但每天都有人踩。
2. **皮尔逊相关对异常值极度敏感**。crypto 一根插针能把相关性从 0.2 拉到 0.7。用 Spearman / Kendall 做稳健性对照。
3. **相关性不稳定，且在危机中趋于 1**。分散化在你最需要它的时候失效。所以风险预算要按"压力场景相关性"而不是"历史平均相关性"来做。

补充工具：
- 距离相关（distance correlation）：能捕捉非线性依赖
- 互信息（mutual information）：非线性、非单调依赖
- Copula：把边缘分布和依赖结构分开建模，尾部相关性专用

## 五、贝叶斯直觉：比公式更重要

不需要精通贝叶斯统计，但必须有这个思维习惯：

> **先验有多不可能，证据就需要有多强。**

应用：
- "我找到了一个夏普 4 的策略" → 先验上这种策略极罕见，所以需要极强证据（长样本、多市场、多时段、成本敏感性全过）才能相信
- 用 Bayesian shrinkage 收缩你的收益预期：估计出的夏普 2.0，考虑到估计误差和先验，真实值可能只有 0.8
- 贝叶斯更新：实盘每周的数据都在更新你对策略真实夏普的后验，别用回测结论固执到底

实用近似做法：**把回测夏普打个 0.5 的折扣，作为实盘预期。** 粗暴，但比不打折靠谱得多。
