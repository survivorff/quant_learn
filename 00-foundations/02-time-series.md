# 02 · 时间序列

> 一句话概括这一章：**价格不能直接建模，收益率可以；但收益率的方向几乎不可预测，波动率可以。**
>
> 时间序列是量化的母语。不懂平稳性，写出的每一行回归代码都是伪回归。

---

## 一、平稳性：为什么不能对价格做回归

### 定义（够用版）

弱平稳 = 均值、方差、自协方差不随时间变化。

价格序列通常是**非平稳**的（随机游走 / 单位根过程）。对两个独立的随机游走做回归，R² 可以很高、t 值可以很显著 —— 这叫**伪回归（spurious regression）**，结论完全是假的。

### 检验

| 检验 | 原假设 | 怎么读 |
|---|---|---|
| ADF | 有单位根（非平稳） | p < 0.05 → 拒绝，序列平稳 |
| KPSS | 平稳 | p < 0.05 → 拒绝，序列非平稳 |
| PP (Phillips-Perron) | 有单位根 | ADF 的稳健版本 |

**实务建议**：ADF 和 KPSS 一起用。两者结论一致才放心；不一致说明序列可能是趋势平稳或分数积分的。

### 平稳化的代价与分数阶差分

标准做法是一阶差分（价格 → 收益率），但这会**擦掉几乎所有记忆**。差分后的序列虽然平稳，但也丢失了"当前价格处于历史什么位置"这类信息。

**分数阶差分（fractional differentiation）** 解决这个矛盾：用非整数阶 d ∈ (0,1) 差分，找到"刚好通过 ADF 检验的最小 d"，在平稳与记忆之间取平衡。

这是 López de Prado 在 AFML 里强调的核心技术之一，也是 ML 因子里被严重低估的预处理步骤。实践中 d 常落在 0.2-0.6。

```python
# 思路（不是完整实现）
# 1. 计算分数阶差分权重序列 w_k
# 2. 对每个 d 从 0 到 1 步进，做 ADF 检验
# 3. 取第一个 p < 0.05 的 d
```

## 二、自相关：方向 vs 波动

| 序列 | 自相关 | 含义 |
|---|---|---|
| 收益率 r_t | 几乎为 0（弱有效） | 方向难预测 |
| \|r_t\| 或 r_t² | 显著且衰减缓慢（长记忆） | **波动率可预测** |
| 高频收益率 | 可能有负自相关 | bid-ask bounce 造成的假象，不是 alpha |

**这张表决定了策略设计的方向**：赌方向是难的，赌波动是相对容易的。所以：
- 波动率策略（做空波动、gamma scalping、波动率择时）有更扎实的统计基础
- 方向策略要么靠很弱但稳定的边（趋势/动量），要么靠结构性错价（套利）

工具：ACF / PACF 图、Ljung-Box 检验、Hurst 指数。

### Hurst 指数

```
H < 0.5  → 均值回归性
H = 0.5  → 随机游走
H > 0.5  → 趋势持续性
```

注意：H 对样本区间和估计方法非常敏感，不同时间尺度上 H 可以完全不同。别把它当作可靠的策略开关，当作探索性指标。

## 三、协整：配对交易的理论基础

### 相关 ≠ 协整

- **相关**：两个序列的**变化**同步
- **协整**：两个非平稳序列存在线性组合 `y - βx` 是平稳的，即**价差会回归**

配对交易赌的是协整，不是相关。相关性 0.95 但不协整的两个币，价差可以无限扩大 —— 这是配对交易爆仓的典型死法。

### 检验方法

| 方法 | 适用 |
|---|---|
| Engle-Granger 两步法 | 两个序列，简单 |
| Johansen 检验 | 多个序列，能找出多个协整关系与最优权重 |
| ADF on spread | 直接对价差做平稳性检验，最直观 |

### 半衰期与 OU 过程

价差建模为 Ornstein-Uhlenbeck 过程：

```
dS_t = θ(μ - S_t)dt + σ dW_t
半衰期 = ln(2) / θ
```

**半衰期是交易频率的锚**：
- 半衰期 2 天 → 持仓周期应在天级
- 半衰期 60 天 → 你需要很深的口袋和很强的耐心
- 半衰期 > 你能承受的持仓时间 → 这个配对不适合你

### Crypto 的现实

- 协整关系**不稳定**。加密资产的基本面/叙事切换极快，"半年前协整"不代表"现在协整"。必须滚动检验并设失效条件。
- 相同 L1 生态内的资产、同一叙事板块内的资产协整概率更高
- 现货-永续、不同交易所同一资产之间的价差是**结构性**的协整关系，比"两个不同币"可靠得多 —— 这才是 crypto 里最扎实的均值回归机会

## 四、波动率建模

### GARCH 家族

```
ARCH(1):    σ²_t = ω + α ε²_{t-1}
GARCH(1,1): σ²_t = ω + α ε²_{t-1} + β σ²_{t-1}
```

`α + β` 接近 1 表示波动率高度持续。金融数据里常见 0.95-0.99。

变体：
| 模型 | 解决什么 |
|---|---|
| EGARCH / GJR-GARCH | 杠杆效应（跌时波动更大） |
| GARCH-t | 残差厚尾 |
| HAR-RV | 用日/周/月已实现波动率做回归，简单且效果好 |
| Realized volatility | 用高频数据算已实现波动，比 GARCH 更直接 |
| Stochastic volatility | 波动率本身是随机过程 |

**实务经验**：预测波动率时，`EWMA` 和 `HAR-RV` 这类简单方法往往不输复杂 GARCH。先做简单的基线。

### 波动率的用途（比预测方向更实用）

1. **仓位缩放**：波动率目标（vol targeting）—— 按 `目标波动/预测波动` 调仓，是最简单有效的风险管理
2. **止损设置**：用 ATR 或预测波动率的倍数，而不是固定百分比
3. **信号过滤**：高波动状态下降低交易频率
4. **期权定价与波动率交易**

## 五、状态切换（regime）

市场不是一个稳定的过程，而是在几个状态间跳转：牛/熊、高波动/低波动、趋势/震荡。

**这解释了为什么策略会"突然失效"** —— 不是失效，是状态换了。

识别方法：
| 方法 | 特点 |
|---|---|
| 阈值规则（波动率分位数、趋势强度） | 最简单，最透明，**推荐先用这个** |
| Markov Regime Switching (HMM) | 概率化状态，但容易过拟合、状态含义不稳定 |
| 聚类（KMeans / GMM on 特征） | 无监督，需要人来解释状态 |
| Change point detection | 检测结构断点 |

**警告**：状态识别有严重的**事后偏差**倾向 —— 回头看总能"识别"出状态，实时判断则困难得多。任何 regime 模型都必须用严格的 walk-forward 验证，且只用截止当前的信息。

实用做法：不追求精确的状态分类，而是用连续的状态变量（如波动率分位数、趋势强度）作为策略的**权重调节器**，避免硬切换带来的不稳定。

## 六、多标的与截面

单标的时间序列之外，量化的主力其实是**截面（cross-section）**：

- **时间序列策略**：对每个标的独立判断多空（趋势跟踪典型）
- **截面策略**：在一个标的池里排序，做多前 N 空后 N（因子选股/选币典型）

截面策略的好处：天然对冲了市场 beta，收益更纯粹是 alpha。这也是因子投资的主流范式。

在 crypto 里做截面：
- 标的池选择极其关键（流动性门槛、上币时间、幸存者偏差）
- 需要处理频繁的上下币、代币经济变更
- 小市值币的可交易性远低于其行情数据看起来的样子
