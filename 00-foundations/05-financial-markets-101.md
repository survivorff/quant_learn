# 05 · 金融市场常识

> 我有 Crypto 一线交易和 CEX 业务经验，但缺的是**把 crypto 放回整个金融市场坐标系里看**的视角。
>
> 这一章补的是：钱到底从哪来。任何策略都必须能回答"我的对手方是谁，他为什么愿意亏给我"。

---

## 一、收益来源的四种类型

这是全仓库最重要的一张表。**任何策略都必须能归到其中一类**，归不进去的，大概率是回测偏差。

| 类型 | 收益本质 | 例子 | 可持续性 | 竞争强度 |
|---|---|---|---|---|
| **风险溢价** | 承担别人不想承担的风险，收补偿 | 市场 beta、carry、卖波动率、提供流动性 | 高（有经济基础） | 低-中 |
| **结构性错价** | 市场机制/摩擦造成的价差 | 期现套利、跨所价差、资金费套利、ETF 折溢价 | 中（会被竞争抹平） | 高 |
| **行为偏差 / 信息优势** | 别人的系统性犯错 | 动量、反转、散户情绪、清算级联 | 中 | 中-高 |
| **速度优势** | 更快看到并反应 | 延迟套利、抢单 | 低（军备竞赛） | 极高 |

### 我该选哪个

| 类型 | 对我的适配度 |
|---|---|
| 风险溢价 | ✅ **最适合**。低频、容量大、不需要拼速度。crypto 里资金费/carry 是最直观的风险溢价 |
| 结构性错价 | ✅ 适合。crypto 市场分割严重（多所、多链），错价机会比传统市场多。我懂交易所机制是优势 |
| 行为偏差 | ⚠️ 可做。crypto 散户占比高、杠杆重，清算级联是重复出现的结构性行为 |
| 速度优势 | ❌ 放弃。个人打不过机构的 colocation 和定制网络栈 |

**结论：主攻风险溢价 + 结构性错价，辅以行为偏差。明确放弃速度竞赛。** 这与 `ROADMAP.md` 的"不做清单"一致。

## 二、市场与工具全景

### 资产类别

| 类别 | 特点 | 量化门槛 |
|---|---|---|
| 股票 | 数据最全、研究最成熟、因子文献海量 | 数据贵（尤其 PIT 数据）；A 股有独特制度 |
| 期货 | 高杠杆、24h 近似连续、trend following 的经典战场 | 需处理合约换月、连续合约拼接 |
| 外汇 | 流动性最深、宏观驱动 | 场外为主，数据碎片化 |
| 期权 | 二维（价格×波动率）、非线性 | 门槛最高，但也最容易找到结构性机会 |
| 债券 / 利率 | 宏观核心 | 定价复杂，个人基本进不去 |
| 大宗商品 | 有真实供需、季节性 | 需要行业知识 |
| **Crypto** | 24/7、高波动、市场分割、数据免费、杠杆易得 | **门槛最低，最适合个人起步** |

### Crypto 为什么是个人量化的最佳起点

| 优势 | 说明 |
|---|---|
| 数据免费且完整 | 交易所 REST/WS API 免费提供 K 线、逐笔、深度。传统市场同等数据要几万美元/年 |
| 24/7 无休市 | 没有隔夜跳空缺口，回测与实盘的行为更一致 |
| 开户门槛低 | 无需资质、无最低资金要求 |
| 波动大 | 收益空间大（风险也大） |
| 市场分割 | 多个交易所、CEX/DEX 并存 → 结构性错价机会多 |
| 独特工具 | 永续合约、资金费率 —— 传统市场没有的收益来源 |
| 散户占比高 | 行为偏差更明显 |

### Crypto 的劣势（必须正视）

| 劣势 | 后果 |
|---|---|
| 交易所风险 | 交易所可能跑路/被黑/冻结提币。**这是最大的非市场风险** |
| 手续费与滑点高 | 相比美股，成本高一个数量级，很多策略在成本面前直接死掉 |
| 历史短 | BTC 才十几年，很多币只有几个月数据，统计样本严重不足 |
| 结构频繁变化 | 上下币、代币经济变更、监管突变、L1 生态迁移 |
| 极端尾部 | 单日 -50%、瞬间插针、交易所宕机、连环强平 |
| 数据质量问题 | 交易所可能刷量；小所深度数据不可信 |
| 监管不确定 | 各司法辖区规则在变 |

**风控优先级**：交易所风险 > 市场风险。资金分散到多个交易所，热钱包只放交易资金，其余上冷钱包。这条比任何策略优化都重要。

## 三、市场参与者：你的对手方是谁

| 参与者 | 行为特征 | 你能从他们身上赚什么 |
|---|---|---|
| 散户 | 追涨杀跌、过度杠杆、FOMO、拿不住盈利单 | 动量延续、清算级联、极端情绪反转 |
| 做市商 | 双边挂单、赚价差与返佣、快速对冲 | 基本赚不到（他们比你快）；可以模仿他们的策略 |
| HFT / 延迟套利者 | 微秒级、吃价差与错价 | 赚不到，只能避开（别在他们的时间尺度上竞争） |
| 量化基金 | 系统化、中低频、容量导向 | 他们吃不下的**小容量**机会归你 |
| 主观基金 / 鲸鱼 | 大单、有信息优势、需要执行时间 | 跟随其链上足迹（crypto 特有优势） |
| 矿工 / 项目方 / VC | 有天然卖压、解锁周期可预测 | 解锁事件、供给冲击的可预测性 |
| 套保盘 | 有真实对冲需求，价格不敏感 | 提供他们需要的流动性，收风险溢价 |

### 关键推论

> **你能赚钱的地方，一定是机构不方便去的地方。**

个人的结构性优势只有三个：
1. **容量小**：能做小市值、冷门合约、小额高频结构性机会
2. **灵活**：不受合规、风控委员会、赎回压力约束
3. **专精**：可以在一个极窄的领域比任何人都懂（对我：crypto 交易所机制 + 链上）

## 四、交易的成本结构（决定生死）

任何策略的净收益 = 毛收益 − 全部成本。crypto 里成本经常吃掉 100%+ 的毛收益。

| 成本项 | 量级（crypto 参考） | 说明 |
|---|---|---|
| Taker 手续费 | 0.02%-0.1% 每边 | 有 VIP 分层，成交量大可降；BNB/平台币抵扣 |
| Maker 手续费 | -0.01%（返佣）到 0.02% | 部分交易所 maker 是负费率，做市策略的基础收入 |
| 买卖价差 | 主流币 < 0.01%，小币可达 1%+ | 吃单必付半个价差 |
| 市场冲击 | 与订单量/深度相关，常用平方根律 | 大单的主要成本，回测最容易低估 |
| 资金费 | 年化 ±10%-100%+ 波动极大 | 持仓成本，也是收益来源 |
| 滑点 | 视流动性与波动 | 高波动时段急剧放大 |
| 链上 gas / MEV 损耗 | 视链与拥堵 | DEX 交易必须算，会被夹 |
| 借贷利率 | 做空/杠杆的成本 | |
| 提币费 / 跨所转账时间 | 跨所套利的隐性约束 | 转账时间是真正的风险窗口 |

### 一个残酷的算术

假设策略每天开平仓一次，taker 双边 0.05%：
- 每天成本 0.1%，一年 250 个交易日 → **年化成本 25%**（不算复利）
- 意味着毛收益必须 > 25% 年化才不亏

**推论：换手率是策略设计的第一约束。** 高频想赚钱必须做 maker、必须有费率优惠。这是为什么"日内策略在纸上很美，实盘一定亏"的原因。

**回测纪律**：手续费按最差档位算（不用 VIP 优惠），滑点按保守估计，然后再问"还赚钱吗"。如果只有在最优费率下才赚钱，说明这个策略没有安全边际。

## 五、频率谱：选对自己的战场

| 频率 | 持仓周期 | 主要挑战 | 个人可行性 |
|---|---|---|---|
| 超高频 (HFT) | 微秒-秒 | 延迟、colocation、定制硬件 | ❌ |
| 高频 | 秒-分钟 | 成本、执行、需 maker 费率 | ⚠️ 做市可尝试，需要工程实力 |
| 中频 | 分钟-小时 | 信号质量、成本控制 | ✅ |
| 低频 | 天-周 | 样本量不足、回撤耐受 | ✅ **推荐起点** |
| 超低频 | 月-年 | 几乎无法统计验证 | 属于配置而非交易 |

**建议起点：低频到中频（小时-天级）**。理由：
- 成本占比可控
- 不需要低延迟基础设施
- 可以和主业并行（不需要盯盘）
- 样本量虽不理想，但可以通过多标的横截面弥补
