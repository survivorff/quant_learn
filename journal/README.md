# journal · 日志与复盘

> **复盘是这个仓库里投入产出比最高的动作。**
>
> 理由：量化的进步不来自"学了更多知识"，来自"发现自己错在哪并改正"。而不记录 = 无法发现。

---

## 三个日志，三个用途

| 文件 | 频率 | 用途 |
|---|---|---|
| [progress.md](./progress.md) | 每日 | 学习打卡：今天学了什么、写了什么代码 |
| [experiment-log.md](./experiment-log.md) | 每次实验 | **试验次数记录**（DSR 修正的必需输入） |
| [trade-journal-template.md](./trade-journal-template.md) | 每交易日 | 实盘复盘：执行质量、PnL 归因、**情绪** |

外加顶层的 [`TRACKING.md`](../TRACKING.md)（每周 KPI）。

---

## 为什么每一个都必要

### progress.md：对抗"学习幻觉"

看资料的时候感觉在进步，但一周后回看发现什么产出都没有。每日一行打卡能暴露这个问题。

**格式极简，降低摩擦**：一行就够，不写就是没做。

### experiment-log.md：DSR 的输入

这是**最容易偷懒、也最致命**的一个。

如果不记录试验次数，你无法计算 Deflated Sharpe Ratio，也就无法知道自己的"发现"里有多少是运气。

> 见 [`03-research-infra/05-evaluation-metrics.md`](../03-research-infra/05-evaluation-metrics.md)：
> 测 500 组参数（一次网格扫描的常规规模），期望会出现 25 个"显著"的假阳性。

**规则：包括失败的实验。** 只记成功的 = 自欺欺人。

### trade-journal-template.md：认识自己

技术问题都有解，心理问题只能靠数据认识。

三个月后回看情绪记录，你会发现：
- 自己的干预冲动在什么情况下最强
- 如果当时干预了会怎样
- 自己真实的风险承受力（而不是想象的）

见 [`03-research-infra/03-backtest-pitfalls.md`](../03-research-infra/03-backtest-pitfalls.md) 第 11 类（心理与执行偏差）。

## 记录的纪律

| 规则 | 原因 |
|---|---|
| **当天记录，不补记** | 补记会美化 |
| **记数字，不记感受**（除情绪栏） | 感受会漂移 |
| **失败也记** | 失败是最有价值的数据 |
| **不修改历史记录** | 一旦修饰过，全部记录的价值归零 |
| 每周日回顾 | 见 `TRACKING.md` |
| 每月回顾一次全部日志 | 找模式 |

**"不修改历史记录"这条最重要。** 它同时是 track record 可信度的基础（见 [`07-career-and-capital/03`](../07-career-and-capital/03-self-trader-capital-plan.md)）。

## Track record（从第一天开始规范记录）

即使不打算管理外部资金，规范记录的成本几乎为零，但如果三年后想走那条路，没记录就是从零开始。

### 需要记录的（实盘开始后）

| 项 | 频率 | 存哪 |
|---|---|---|
| 每日净值 | 每日 | `track-record/nav.csv` |
| 每笔交易明细 | 实时 | `track-record/trades/` |
| 持仓快照 | 每日 | `track-record/positions/` |
| 资金变动（入金/出金） | 事件 | `track-record/cashflow.csv` |
| 月度报告 | 每月 | `track-record/monthly/` |

### 提升可信度

- 用交易所 API 导出原始数据（可验证）
- 净值与交易所对账单一致
- 记录入出金，用时间加权收益率
- 永不修改历史

> `track-record/` 目录已在 `.gitignore` 覆盖范围内考虑 —— **具体持仓和资金规模不要公开**。但净值曲线和统计指标可以选择性公开。

## 每月回顾要回答的问题

每月最后一周，翻一遍三个日志，回答：

1. 这个月最大的进展是什么？（能被别人验证的）
2. 这个月最大的时间浪费是什么？
3. 我在哪个环节反复卡住？（说明有系统性问题）
4. 我的实验里有多少是"换个参数再试一次"？（说明在做曲线拟合）
5. 我的情绪记录里有什么模式？
6. 路线要不要调整？为什么？

**第 4 题最能暴露问题。** 如果大部分实验都是微调参数，说明我在做无效劳动 —— 真正的进展来自"换一个假设"，不是"换一个参数"。
