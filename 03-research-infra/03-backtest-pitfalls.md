# 03 · 回测陷阱（本仓库最重要的一章）

> **默认假设：任何漂亮的回测结果都是错的，直到你排除了下面全部 11 类问题。**
>
> 这不是悲观，是概率。绝大多数策略想法是无效的，所以一个"有效"的结果，先验上更可能是 bug 或过拟合，而不是真发现。

## 1. 未来函数（最常见、最致命）

用了当时不可得的信息。

### 常见形态

| 形态 | 例子 |
|---|---|
| 信号与收益同期 | 用 bar t 的收盘信号，按 bar t 的收盘价成交 |
| `shift` 方向错误 | 见 [`00-foundations/04-python-data-stack.md`](../00-foundations/04-python-data-stack.md) |
| 全样本统计量 | 用全样本均值/标准差/分位数做标准化 |
| 全样本参数拟合 | 用全样本 OLS 估计对冲比率、用全样本 PCA |
| 反向填充 | `bfill`、`interpolate` |
| 数据修订 | 用今天的修正后数据当作当时的数据 |
| 标的池用今天的列表 | 同时也是幸存者偏差 |
| 元数据泄漏 | 链上地址标签、板块分类、市值数据都是"今天的知识" |
| 标签重叠 | ML 里训练集的标签用到了测试集期间的价格 |
| 事件时间戳用日期而非时刻 | "公告日"买入，实际公告在收盘后 |
| 归一化在切分前做 | `scaler.fit(all_data)` 然后再切训练测试 |

### 检测方法

1. **异常值注入测试**：在测试期某点插入极端值，验证之前的结果不变
2. **时间倒序测试**：把数据倒过来跑，如果策略还赚钱，说明它在用双向信息
3. **代码审计**：搜索所有 `.mean()`、`.std()`、`.quantile()`、`fit()`、`bfill`，逐个确认是否用了滚动窗口
4. **事件驱动回测**：从架构上禁止访问未来（最可靠的方案）

### 危害量级

未来函数能把一个零期望策略的夏普推到 5 以上。**它是"太好看的回测"的第一嫌疑人。**

## 2. 幸存者偏差

只用现在还活着的标的。

### crypto 里为什么更严重

币的死亡率远高于股票。大量代币归零、下架、项目跑路。只用现存标的，等于事后选择了赢家。

### 必须做的

- 维护含下架标的的完整历史标的池
- 按时间点动态确定可交易标的
- 区分"因流动性下架"与"归零"
- 跑对比实验量化偏差幅度

### 相关的隐蔽形式

| 形式 | 说明 |
|---|---|
| 交易所幸存者偏差 | 只用还活着的交易所的数据 |
| 策略幸存者偏差 | 只报告"跑通了"的策略，忘了淘汰的几十个 |
| 数据源幸存者偏差 | 某些历史数据只有活跃标的才有 |

## 3. 过拟合与多重检验

### 机制

参数扫描 500 组，取最好的那组。在纯随机数据上，最好的那组也会有很漂亮的夏普。这不是发现，是选择偏差。

### 症状

| 症状 | 说明 |
|---|---|
| 参数尖峰 | 最优参数附近的表现急剧变差（应该是"参数平原"） |
| 样本内外落差大 | 样本内夏普 3.0，样本外 0.2 |
| 参数值奇怪 | "17 日均线配 43 日均线"这种精确值 |
| 规则复杂 | 一堆 if-else 条件叠加 |
| 依赖少数交易 | 剔除最好的 5 笔交易后收益消失 |
| 换标的失效 | 只在某一个币上有效 |
| 换时段失效 | 只在某一年有效 |

### 防御手段

| 手段 | 做法 |
|---|---|
| **记录试验次数** | 每次参数扫描、每个策略变体都计数。**这是 DSR 修正的输入** |
| Deflated Sharpe Ratio | 按试验次数惩罚夏普 |
| PBO（过拟合概率） | 用 CSCV 估计"样本内最优在样本外垫底"的概率 |
| **多周期平均代替选参数** | 见 [`02-strategy-zoo/01-trend-momentum.md`](../02-strategy-zoo/01-trend-momentum.md)：不选最优，用多个参数平均 |
| 参数热力图 | 看是平原还是尖峰 |
| 剔除极端交易检验 | 去掉最好的 5% 交易后是否还正 |
| 保留真正的 holdout | 一段数据看都不看，直到最后 |
| 限制自由度 | 参数越少越好；规则越简单越好 |
| CPCV | 见 [`05-evaluation-metrics.md`](./05-evaluation-metrics.md) |

### 最重要的一条纪律

> **holdout 数据只能用一次。** 一旦你看了它并据此调整策略，它就不再是样本外了。
>
> 如果你已经在 holdout 上试过 3 次，那你实际上是在做参数拟合，只是自欺欺人。

## 4. 成本低估

见 [`01-market-microstructure/02-execution-costs-and-slippage.md`](../01-market-microstructure/02-execution-costs-and-slippage.md) 的完整讨论。

### 最容易漏的成本（crypto）

- **资金费**：持仓永续必付，年化可达数十个百分点
- 借贷利率（做空、杠杆）
- 手续费档位（用了 VIP 优惠但实际达不到那个量）
- 深度不足导致的多档滑点
- 高波动时段的滑点放大
- 部分成交后的补单成本
- 划转/提币费用与时间成本
- 链上 gas 与 MEV 损耗

### 检查

- [ ] 成本按**最差档位**算（不用 VIP 优惠）
- [ ] 做成本敏感性分析（0 → 2 倍保守估计）
- [ ] 计算成本盈亏平衡点
- [ ] **只接受 2 倍保守成本下仍正期望的策略**
- [ ] 报告"成本占毛收益比例"

## 5. 容量幻觉与流动性

### 问题

回测假设你能在任意价格成交任意数量。实际上：

| 问题 | 说明 |
|---|---|
| 深度不足 | 你的订单量超过盘口深度 |
| 冲击成本 | 见平方根律，量大成本非线性上升 |
| 流动性消失 | 你想成交时别人撤单了（liquidity fade） |
| 极端行情无法交易 | 交易所限流、拒单、暂停 |
| 小市值标的不可交易 | 行情数据看起来正常，实际打不进去 |

### 检查

- [ ] 每笔订单量 vs 该时刻实际深度的比例（设上限，如 20%）
- [ ] 每笔订单量 vs 该周期成交量的比例（设上限，如 5%）
- [ ] 用真实深度数据做逐档成交模拟（L3 成本模型）
- [ ] 估计策略容量：资金放大 10 倍后夏普如何衰减
- [ ] 标的池按真实可交易性筛选，不只看行情有数据

### 截面策略的特殊陷阱

排名靠前的往往是"刚暴涨的小币"——正是流动性最差、最打不进去的。这会让截面策略的回测系统性虚高。

## 6. 数据挖掘偏差与选择性报告

### 形态

- 试了 50 个策略，只记录成功的那个（然后忘了自己试过 50 个）
- 换了 5 个标的池，报告表现最好的
- 调整了回测区间，让曲线更好看
- 事后加了一个"过滤条件"排除亏损时段（本质是曲线拟合）
- 发现某年表现差，说"那年是特殊情况"然后排除

### 防御

**建立"实验日志"，记录每一次尝试，包括失败的。**

```markdown
| 日期 | 策略/参数 | 结果 | 是否继续 | 备注 |
|---|---|---|---|---|
| 09-06 | EWMAC(16,64) BTC | SR 0.8 | 是 | |
| 09-06 | EWMAC(8,32) BTC | SR 0.3 | 否 | |
| 09-07 | RSI 反转 | SR -0.2 | 淘汰 | |
```

累计试验次数是 DSR 修正的必需输入。见 [`journal/`](../journal/)。

## 7. 制度变化与结构断裂

### crypto 里的常见断裂

| 变化 | 影响 |
|---|---|
| 交易所费率结构调整 | 策略成本模型失效 |
| 新产品上线（如新的永续类型） | 市场结构变化 |
| 监管变化 | 某些市场突然不可用 |
| 主要参与者进出（机构入场/退出） | 市场效率提升，alpha 消失 |
| L1 生态迁移 | 链上因子失效 |
| 代币经济变更 | 单个标的的行为改变 |
| 市场成熟化 | 早年有效的简单策略被套利掉 |

### 检查

- [ ] 分时段（按年/按市场状态）回测，看表现是否一致
- [ ] 特别关注：**早期数据表现好、近期变差** —— 这是 alpha 衰减的信号
- [ ] 只用近期数据也验证一遍（哪怕样本量少）
- [ ] 识别策略依赖的"制度假设"，写在策略档案的"失效条件"里

### 关键判断

如果一个策略只在 2017-2020 有效、2023 之后失效，那它已经死了。**用全样本回测会掩盖这一点。**

## 8. 尾部风险被平均掉

### 问题

夏普比率用标准差衡量风险，但：
- 它假设近似正态
- 它对偏度和峰度不敏感
- 一个"5 年稳定盈利 + 第 6 年归零"的策略，前 5 年的夏普会非常漂亮

### 典型的隐藏尾部风险策略

| 策略 | 隐藏风险 |
|---|---|
| 裸卖期权 | 极端行情巨亏 |
| 高杠杆 carry | 强平 |
| 均值回归（无止损） | 关系断裂 |
| 网格交易 | 单边趋势 |
| 卖波动率 | 波动率跳升 |
| 做市（库存无上限） | 单边行情 |

**共同特征：高胜率 + 负偏 + "看起来很稳"。**

### 检查

- [ ] 报告偏度、峰度，不只报夏普
- [ ] 报告最大回撤、最长水下时长
- [ ] 做压力测试：标的 ±50%、波动率翻倍、相关性趋于 1
- [ ] 用历史极端事件重放（找出历史上最糟的几天）
- [ ] 问："如果最坏的一天比历史最坏再糟 2 倍，我会怎样"
- [ ] 用 Calmar、Sortino、CVaR 补充夏普

## 9. 执行假设不现实

| 假设 | 现实 |
|---|---|
| 限价单必然成交 | 可能一直挂着不成交 |
| 全部成交 | 部分成交是常态 |
| 无延迟 | 有延迟且有长尾 |
| 无拒单 | 精度错误、保证金不足、限流都会拒单 |
| 可在任意时刻交易 | 交易所会宕机、限流、暂停 |
| 止损按止损价成交 | 跳空时会以更差价格成交（甚至无法成交） |
| 能随时撤单 | 高波动时撤单可能失败或延迟 |
| 一个 bar 内能完成多个动作 | 实际受限于延迟 |

### 检查

- [ ] 限价单建模了不成交的情况
- [ ] 建模了部分成交
- [ ] 建模了延迟（含长尾）
- [ ] 止损按"跳空后的实际价格"而非止损价计算
- [ ] 模拟了交易所不可用的时段

## 10. 拥挤度与自我毁灭

### 问题

策略的收益来源是有限的。参与者越多，收益越薄。

而且，**你的回测数据来自"这个策略还没被广泛发现"的时期**。

### 检查

- [ ] 这个策略公开程度如何？（教科书 / 论文 / 圈内 / 小众）
- [ ] 有没有可观测的拥挤度代理指标？（OI、资金费、价差收窄趋势）
- [ ] 近期表现 vs 早期表现的对比（衰减趋势）
- [ ] 容量估计：如果资金规模的策略都在做，还有多少空间

### 一个诚实的判断

如果你在 GitHub 上搜到一个"夏普 3.0"的开源策略，那它已经不值 3.0 了。**能公开的 alpha 不是 alpha。**

## 11. 心理与执行偏差（最难防）

回测里没有的东西：

| 现实 | 影响 |
|---|---|
| 回撤期的心理压力 | 你会在最痛的时候停掉策略（正好是它该赚钱的时候） |
| 干预冲动 | 手动改仓、提前止盈、跳过信号 |
| 参数微调冲动 | 表现不好就调参数，本质是实时过拟合 |
| 策略切换 | 追逐最近表现好的策略（时间序列上的追涨） |
| 加杠杆冲动 | 顺利时加杠杆，正好在均值回归前 |

### 防御

- [ ] **在实盘前写下"什么情况下我会停掉这个策略"** —— 数字化，不许临时改
- [ ] 全自动执行，减少人工介入的机会
- [ ] 设定"冷静期"：任何策略改动必须等 24 小时后再执行
- [ ] 交易日志记录情绪（见 [`journal/trade-journal-template.md`](../journal/trade-journal-template.md)）
- [ ] 提前接受"回撤是正常的"，并知道自己策略的历史最大回撤和最长水下时长

**这一条是从"能做出策略"到"能靠策略赚钱"之间最大的鸿沟。** 技术问题都有解，心理问题只能靠预先建立的规则约束。

## 附：一个自我审查的提问

回测出好结果时，按顺序问自己：

1. 这个结果好到什么程度？（好得离谱 → 高度怀疑）
2. 我的收益来源是什么？谁在亏给我？
3. 我一共试了多少次才得到这个结果？
4. 成本翻倍还赚钱吗？
5. 换标的、换时段还有效吗？
6. 我用了任何"今天才知道"的信息吗？
7. 我的容量是多少？
8. 最坏情况长什么样？
9. 为什么别人没做这件事？
10. 如果这个策略是别人给我看的，我会相信吗？

**第 10 个问题最有效。** 对自己的成果我们都有偏袒，换成"别人的策略"，你的怀疑水平会立刻回到正常。
