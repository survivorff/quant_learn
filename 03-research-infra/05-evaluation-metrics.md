# 05 · 评估指标与验证方法

> 回测告诉你"过去会怎样"，验证告诉你"这个结论可信吗"。**后者更重要。**
>
> 一句话总结这一章：**单一夏普比率是最没用的指标，因为它同时隐藏了过拟合、尾部风险和成本。**

---

## 一、指标体系

### 收益类

| 指标 | 定义 | 注意 |
|---|---|---|
| 累计收益 | 期末/期初 | 受起止时点影响大，别单看 |
| 年化收益 (CAGR) | 几何年化 | 用几何不用算术 |
| 月度/年度收益分布 | 分期表现 | **必看**：是稳定还是靠某一段 |

### 风险类

| 指标 | 定义 | 为什么重要 |
|---|---|---|
| 年化波动率 | σ × √N | crypto 用 365 |
| **最大回撤 (MDD)** | 峰值到谷值最大跌幅 | 决定你能否活到策略生效 |
| **最长水下时长** | 从回撤开始到回新高的时间 | **心理上比 MDD 更难熬**，但常被忽略 |
| 下行波动率 | 只算负收益的标准差 | |
| VaR / CVaR | 分位数损失 / 尾部期望损失 | 用历史模拟法，别用正态假设 |
| **偏度 / 峰度** | 分布形状 | 揭示夏普隐藏的尾部风险 |
| 最差单日/单周 | 极端单期损失 | 压力测试的输入 |

### 风险调整类

| 指标 | 公式 | 特点 |
|---|---|---|
| Sharpe | (R − Rf) / σ | 最常用，但对非正态不敏感 |
| Sortino | (R − Rf) / σ_下行 | 只惩罚下行波动 |
| **Calmar** | 年化收益 / MDD | **对回撤敏感，实务中很有用** |
| Omega | 上行概率加权 / 下行 | 不依赖分布假设 |
| **Deflated Sharpe (DSR)** | 按试验次数与非正态性惩罚的夏普 | **必报**，见下文 |
| Probabilistic Sharpe (PSR) | 夏普 > 阈值的概率 | 考虑估计不确定性 |

### 交易类

| 指标 | 用途 |
|---|---|
| 交易次数 | 样本量是否足够 |
| 胜率 | 配合盈亏比看 |
| 盈亏比 | 平均盈利 / 平均亏损 |
| 平均持仓周期 | 与 IC 衰减曲线是否一致 |
| 换手率 | 成本敏感度 |
| **成本占毛收益比例** | **策略健康度核心指标** |
| maker 成交占比 | 执行质量 |
| 最大连续亏损次数 | 心理承受力测试 |
| 收益集中度 | 剔除最好 5% 交易后还剩多少 |

### 我的"必报六项"

任何策略报告，这六个数字必须同时出现：

1. 年化收益
2. **最大回撤 + 最长水下时长**
3. **Deflated Sharpe Ratio**（不是原始夏普）
4. **成本占毛收益比例**
5. 偏度
6. **试验次数**

**只报夏普的策略报告，等于没报。**

## 二、Deflated Sharpe Ratio（必须理解并使用）

### 为什么需要它

原始夏普不知道你试了多少次。试 500 组参数取最好，那个夏普天然虚高。

DSR 的思路：
1. 估计"在 N 次独立试验下，纯随机策略能达到的最高期望夏普"（这是基准）
2. 把你的夏普与这个基准比较
3. 同时校正非正态性（偏度、峰度会影响夏普的估计分布）

结果是一个"这个夏普真实不为零的概率"。

### 使用要求

**必须诚实记录试验次数。** 这包括：
- 参数扫描的组合数
- 尝试过的策略变体数
- 换过的标的池数
- 调整过的回测区间数

**累计计数，不是单次会话。** 如果你在同一个策略想法上折腾了两周，试验次数是这两周的总和。

> 这条纪律是自我诚实的试金石。低报试验次数 = 骗自己 = 用真金白银交学费。

## 三、验证方法（按可靠性递增）

### 1. 简单切分（train / test）

```
|————— 训练 70% —————|—— 测试 30% ——|
```

问题：
- 只有一次样本外，统计功效低
- 一旦你看了测试集并调整，它就污染了
- 无法评估结果的方差

**结论：不够，只能当第一道筛子。**

### 2. Walk-forward（滚动前推）

```
训练[1-12月] → 测试[13月]
训练[2-13月] → 测试[14月]
训练[3-14月] → 测试[15月]
...
```

| 优点 | 缺点 |
|---|---|
| 模拟真实的"用过去预测未来" | 只有一条时间路径 |
| 多个样本外窗口 | 后期窗口的训练数据包含了前期测试数据 |
| 能观察策略随时间的稳定性 | 计算量大 |

两种变体：
- **锚定式（anchored）**：训练集起点固定，逐渐变长
- **滚动式（rolling）**：训练集长度固定，窗口滑动

**推荐：滚动式**，因为它能反映"制度变化"（旧数据可能已无参考价值）。

### 3. Purged K-Fold with Embargo

金融时序做交叉验证的问题：**标签重叠导致信息泄漏**。

如果你的标签是"未来 5 天的收益"，那第 t 天的标签用到了 t+5 的价格。如果第 t+3 天在测试集，那训练集的第 t 天标签已经"看到"了测试集的信息。

解决：
- **Purging（清除）**：删除训练集中与测试集标签期重叠的样本
- **Embargo（禁运）**：在测试集之后额外留出一段缓冲期（防止序列相关造成的泄漏）

```
训练  |████████|--purge--|  测试  |--embargo--|████████|
```

### 4. CPCV（组合 Purged 交叉验证）

**目前公认最可靠的金融时序验证方法**（López de Prado 提出）。

思路：
1. 把数据分成 N 组
2. 每次选 k 组作为测试集，其余训练（做 purging + embargo）
3. 遍历所有 C(N,k) 种组合
4. 得到**多条**回测路径，而非一条

关键价值：**你得到夏普的分布，而不是一个点估计。**

这让你能回答：
- 我的夏普的置信区间是多少？
- 有多少条路径是亏钱的？
- **PBO（过拟合概率）**：样本内最优参数在样本外排名垫底的概率

### PBO 的解读

| PBO | 含义 |
|---|---|
| < 0.2 | 过拟合风险较低 |
| 0.2 - 0.5 | 需要谨慎 |
| > 0.5 | **样本内最优在样本外基本是随机的，你的"优化"没有价值** |

## 四、压力测试（回测之外的必需环节）

回测只覆盖历史发生过的事。压力测试覆盖"没发生但可能发生"的事。

| 场景 | 怎么做 |
|---|---|
| 极端价格冲击 | 标的瞬间 ±30% / ±50% |
| 波动率跳升 | 波动率翻 2-3 倍 |
| **相关性趋于 1** | 所有分散化失效，同时亏损 |
| 流动性枯竭 | 深度减少 90%，滑点放大 5 倍 |
| 交易所不可用 | 无法下单/撤单持续 N 小时 |
| 资金费极端 | 资金费反向且达到历史极值 |
| 强平模拟 | 保证金率降到临界，验证强平损失 |
| 历史最坏日重放 | 找出历史上最糟的 5 天，看策略表现 |
| 历史最坏日 ×2 | 假设比历史最坏再糟一倍 |
| 连续亏损 | 假设连续 20 次亏损（对高胜率策略特别重要） |

**规则：如果任何一个压力场景会导致资金损失超过可承受范围，策略不许上实盘，必须先加约束。**
