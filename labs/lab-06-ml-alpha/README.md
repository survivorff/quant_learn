# lab-06: ML alpha 全流程

> 目标**不是**"用 ML 找到高夏普策略"，而是**掌握金融 ML 的正确方法论**，并诚实量化样本外衰减。
>
> 前置纪律：**先把 lab-03 的验证流水线建好，再上 ML。** ML 让你能更快地过拟合。

**状态**：未开始
**依赖**：lab-03（必须先有 CPCV + DSR 验证能力）
**对应知识**：[`04-ml-and-frontier/01-ml-for-finance.md`](../../04-ml-and-frontier/01-ml-for-finance.md)

---

## 解决什么问题

把 sklearn 的标准流程套到金融数据上，几乎必然得到错误结论（非 IID、标签重叠、信噪比极低、有对抗性）。

这个 lab 要实现 López de Prado 的 AFML 方法论，并**用它验证"方法论比模型重要"这个判断**。

---

## 目标

### 数据结构

- [ ] **Dollar bar**（固定成交金额），对比 time bar 的统计性质
- [ ] Volume bar、Tick bar（对照）
- [ ] 验证：dollar bar 的收益率分布更接近正态、序列相关更弱

### 事件驱动采样

- [ ] **CUSUM 过滤器**（累积偏离超阈值才触发）
- [ ] 对照：对每个 bar 预测 vs 只对筛选出的事件预测

### 标签构造

- [ ] **三重障碍法**（上下障碍按波动率缩放 + 时间障碍）
- [ ] 对照：朴素的"未来 N 期收益符号"
- [ ] 对比两者的信噪比与模型表现

### 样本权重

- [ ] **平均唯一性**（uniqueness）计算
- [ ] 时间衰减权重
- [ ] 顺序自举（sequential bootstrap）
- [ ] 对照：不加权重的结果

### 特征

- [ ] 从 lab-03 的因子库取特征
- [ ] **分数阶差分**处理价格类特征
- [ ] 微观结构特征（OFI、spread、depth）
- [ ] crypto 特有特征（资金费、OI、清算量）
- [ ] 特征数量控制（**不要塞 100+ 个**）

### 模型

- [ ] **线性/Ridge 基线**（必须做，打不过它的复杂模型没有价值）
- [ ] LightGBM（主力）
- [ ] 随机森林 + 顺序自举
- [ ] 正则化：限制深度（3-6 层）、min_child_samples、subsample
- [ ] 早停（用时序正确的验证集）

### 元标注（重点）

- [ ] **主模型 = lab-02 的趋势策略**（经济逻辑清晰、可解释）
- [ ] **二级模型 = LightGBM**，预测"这次信号是否盈利"
- [ ] 输入：波动率状态、资金费、OI、市场宽度、微观结构特征
- [ ] 输出 → 映射到仓位
- [ ] 对比：加元标注前后的夏普、胜率、最大回撤

> **这是我用 ML 的首选切入点**：保留策略的可解释性和经济逻辑，用 ML 提升执行质量。比"端到端让 ML 决定买卖"稳健得多。

### 验证

- [ ] **CPCV**（purging + embargo），输出夏普分布
- [ ] **PBO**（过拟合概率）
- [ ] **Deflated Sharpe Ratio**（含累计试验次数）
- [ ] 成本敏感性（0 → 2 倍）
- [ ] 学习曲线（数据量 vs 样本外性能）

### 特征重要性

- [ ] **MDA**（置换重要性）
- [ ] **SHAP**
- [ ] 对照 MDI，观察差异
- [ ] 聚类特征重要性（解决相关特征稀释）

## 核心实验（这个 lab 的真正价值）

| 实验 | 要回答什么 |
|---|---|
| 三重障碍 vs 朴素标签 | 标签构造的影响有多大 |
| 加权重 vs 不加权重 | 样本权重的影响 |
| CPCV vs 简单切分 | 简单切分会高估多少 |
| **LightGBM vs 线性基线** | 复杂模型真的更好吗 |
| **元标注 前 vs 后** | 元标注能提升多少 |
| Dollar bar vs Time bar | bar 类型的影响 |
| 事件采样 vs 全 bar | 信噪比的改善 |
| **样本内外衰减归因** | 衰减来自哪一类原因 |
| MDA vs MDI | 特征重要性的差异 |

### 样本外衰减的归因（最重要的实验）

按 [`04-ml-and-frontier/01`](../../04-ml-and-frontier/01-ml-for-finance.md) 第七节的表格逐条排查：

1. 信息泄漏（未来函数）
2. 验证方法有泄漏（没做 purging）
3. 过拟合
4. 制度变化
5. 标签构造问题
6. 特征分布漂移
7. 样本量不足
8. 真实 alpha 就是很小

**先排除 1-3（自己的错），再考虑 4-8（市场的原因）。** 大多数人跳过前三个直接归因"市场变了"。

## 怎么验证正确性

- [ ] **在纯随机数据上跑完整流程**，验证 DSR 和 PBO 能识别出"这是噪声"
- [ ] 未来函数测试：故意用不做 purging 的 CV，对比结果虚高多少
- [ ] 手工验证三重障碍标签（小样本逐条核对）
- [ ] 手工验证唯一性计算
- [ ] 多随机种子（≥5），报告分布而非最好结果
- [ ] 与线性基线对比，确认复杂度换来了实质改进
