# lab-04: 订单簿与做市模拟

> 目的**不是**马上去做市，而是理解逆向选择和库存风险的真实量级。
>
> 这个 lab 的产出主要是**认知**：搞清楚"个人在什么条件下做市可行"。

**状态**：未开始
**依赖**：lab-01（需要 L2 深度数据）
**对应知识**：[`02-strategy-zoo/03-market-making.md`](../../02-strategy-zoo/03-market-making.md)、[`01-market-microstructure/01`](../../01-market-microstructure/01-order-book-and-matching.md)

---

## 解决什么问题

做市看起来简单（两边挂单赚价差），但实际盈亏是：

```
价差收入 + maker 返佣 − 逆向选择损失 − 库存风险损失 − 技术成本
```

**逆向选择损失通常是最大的一项，而它在朴素回测里完全不可见。**

这个 lab 要把它量化出来。

---

## 目标

### 订单簿模拟器（核心）

- [ ] 从历史 L2 深度快照重建订单簿
- [ ] **队列位置模拟**：记录挂单时该价位已有的量，只有前面的量被吃完才成交
- [ ] **延迟建模**：行情延迟 + 下单延迟，用实测分布采样（含长尾）
- [ ] 部分成交
- [ ] 撤单竞争（想撤时可能已成交）
- [ ] 逆向选择的自然涌现（不需要专门建模，队列 + 延迟会自然产生）

> **没有队列位置和延迟建模的做市回测，结果毫无意义。** 这是做市回测最大的坑。

### 报价逻辑

- [ ] 公允价计算：mid price vs **microprice** vs 多所加权
- [ ] Avellaneda-Stoikov 保留价格与库存偏斜
- [ ] 动态价差（波动率项 + 成本项 + 竞争调整）
- [ ] Post-only 挂单
- [ ] 改价节流（价格偏离阈值 + 最小改价间隔）
- [ ] 趋势过滤器（单边趋势中暂停不利方向报价）

### 库存管理

- [ ] 库存偏斜（自动回归中性）
- [ ] 硬上限（触及则停止单边报价）
- [ ] 主动对冲（超阈值则 taker 平掉一部分）
- [ ] 时间衰减（持仓过久强制减仓）

### 微观结构特征

- [ ] spread、depth、microprice、book imbalance
- [ ] **OFI（订单流失衡）**
- [ ] 撤单率统计

## 关键实验（这个 lab 的核心产出）

| 实验 | 要回答什么 |
|---|---|
| **量化逆向选择** | 统计"成交后 N 秒的价格变动"，看是否系统性不利。**这个数字决定做市可行性** |
| **延迟敏感性** | 延迟从 1ms 加到 500ms，盈亏怎么变 → 告诉我需要多快 |
| mid vs microprice | 用 microprice 作为公允价能改善多少 |
| 库存偏斜效果 | 观察库存如何自动回归中性 |
| 对冲 vs 不对冲 | 尾部风险的差异（新手常见错误是为省手续费不对冲） |
| 价差宽度扫描 | 价差与成交量、盈亏的关系，找可行区间 |
| 趋势过滤器 | 加上之后是否改善 |
| **maker 返佣的影响** | 返佣从 0 到负费率，盈亏如何变化 |
| 标的流动性对比 | 主流币 vs 中等流动性标的，哪个可行 |

### 最重要的三个数字

做完这个 lab，我要能回答：

1. **逆向选择成本是多少 bps？**
2. **我需要多低的延迟才能盈利？**
3. **在什么流动性水平的标的上，个人做市才可行？**

如果答案是"需要亚毫秒延迟"或"只在主流币可行"，那结论就是：**不做市**。这也是有价值的结论。

## 设计决策与取舍（待填）

### 预期难点

1. L2 深度快照的采样频率（太稀疏无法模拟队列，太密集数据量爆炸）
2. 队列位置的近似（无法知道前面的单是被成交还是被撤）
3. 延迟分布的获取（需要真实实测数据）
4. 自己的订单对市场的影响（模拟器里通常忽略，但会高估收益）

---

## 怎么验证正确性

- [ ] 极端策略测试：报极宽价差（应该几乎不成交）、报极窄价差（应该大量成交且亏钱）
- [ ] 零价差测试：买卖同价，应该快速累积库存并亏损
- [ ] 队列位置测试：构造场景验证排队逻辑正确
- [ ] 与实际数据对比：模拟的成交率与真实盘口的成交率量级是否合理
- [ ] 延迟为 0 时的结果 vs 有延迟的结果，差异应该显著

**"极端策略测试"能发现模拟器的 bug** —— 如果报极窄价差还能赚钱，说明没建模逆向选择。
