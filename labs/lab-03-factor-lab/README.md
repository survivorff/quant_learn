# lab-03: 因子研究流水线

> 目标是**研究吞吐量**：一个新因子想法，30 分钟内出完整评估报告。
>
> 在一个"绝大多数想法都无效"的领域，吞吐量就是竞争力。这也是我第二个作品级项目。

**状态**：未开始
**依赖**：lab-01、lab-02
**对应知识**：[`03-research-infra/04-factor-research-workflow.md`](../../03-research-infra/04-factor-research-workflow.md)、[`05-evaluation-metrics.md`](../../03-research-infra/05-evaluation-metrics.md)

---

## 解决什么问题

手工研究因子的流程是：写代码 → 跑 Notebook → 看图 → 判断。问题：
- 慢（每个因子几小时）
- 不一致（每次看的指标不一样）
- 会偷懒（跳过检查项，而跳过的那项往往就是问题所在）
- 不可复现（Notebook 执行顺序不可靠）

流水线化之后：因子定义 → 一条命令 → 完整报告。**强制执行全部检查项。**

## 目标

### 因子定义与注册

- [ ] 因子定义的 yaml schema（含 `hypothesis` 和 `expected_sign`）
- [ ] 因子注册机制
- [ ] 因子计算框架（输入数据面板，输出因子面板，支持缓存）

```yaml
factor_id: funding_zscore_7d
name: 资金费率 7 日 z-score
category: 情绪/拥挤度
data_requirements: [funding_rate]
lookback: 7d
hypothesis: 资金费极端为正 = 多头拥挤 = 短期反转风险
expected_sign: -1
economic_rationale: 行为偏差 + 拥挤度
```

**`hypothesis` 和 `expected_sign` 是纪律装置**：先写预期，再看结果。符号相反就淘汰，不许事后改解释。

### 预处理（全部滚动窗口）

- [ ] 缺失值处理（标记而非填充）
- [ ] 去极值（MAD 法）
- [ ] 标准化（截面 z-score / rank 百分位）
- [ ] **beta 中性化**（对 BTC beta 回归取残差）
- [ ] 可选平滑

> **crypto 里 beta 中性化是必须的。** 不做，测出的"因子有效"很可能只是"高 beta 币在牛市涨更多"。

### 评估指标

- [ ] IC / Rank IC 时间序列
- [ ] IC 均值 / 标准差 / **IR** / 胜率 / t 值
- [ ] **IC 衰减曲线**（决定最优持仓周期）
- [ ] 分层回测（5 或 10 组）+ 单调性检查
- [ ] 多空组合净值与回撤
- [ ] 换手率与成本估算
- [ ] **净收益**（扣成本后）

### 稳健性检验矩阵（9 项）

- [ ] 分时段（按年 / 按市场状态）
- [ ] 分标的组（大 / 中 / 小市值）
- [ ] 参数敏感性（lookback 扫描）
- [ ] 剔除最好 5% 时段
- [ ] 不同标的池
- [ ] 中性化前后对比
- [ ] 与已有因子的相关性
- [ ] 成本敏感性（0 → 2 倍）
- [ ] PIT 检验

### 验证层

- [ ] Walk-forward（锚定式 + 滚动式）
- [ ] Purged K-Fold with embargo
- [ ] **CPCV**（输出夏普分布 + PBO）
- [ ] **Deflated Sharpe Ratio**
- [ ] **试验次数追踪器**（累计计数，接入 DSR）

### 多因子

- [ ] 因子相关性矩阵与热力图
- [ ] 正交化（对已有因子回归取残差）
- [ ] 合成方法（等权基线 + IR 加权）
- [ ] 因子库管理（元数据 + 状态 + 衰减监控）

## 怎么验证正确性

- [ ] 用一个**已知有效**的因子（如经典动量）验证流水线能识别出来
- [ ] 用一个**纯随机**因子验证流水线能识别为无效
- [ ] **在纯随机数据上跑参数扫描，验证 DSR 和 PBO 能正确识别"这是噪声"**
- [ ] 手工计算一个小样本的 IC，与流水线结果对比
- [ ] 未来函数测试：故意用全样本标准化，看 IC 虚高多少
- [ ] 30 分钟目标验证：用 5 个新因子实测端到端耗时

**倒数第三条（在随机数据上验证验证工具）是元级别的检查**，非常值得做 —— 它验证的是"我的验证工具本身可靠吗"。

---

## 配套的动手实验

- [ ] **量化 beta 中性化的影响**：同一因子中性化前后的 IC 对比（差异会很大）
- [ ] 筛选 100 个币对做协整检验，用 FDR 修正，看还剩几个显著
- [ ] 用资金费 z-score 作为反转因子，测 IC
- [ ] OI-价格四象限分析，检验各象限后续收益差异
- [ ] 把 IV / skew 作为特征加入趋势策略（最实用的一步）
- [ ] 对情绪因子做价格动量中性化，看是否还有独立 IC
