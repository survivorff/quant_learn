# 07 · 转型路径与资金

> 这一章讨论一个绕不开的现实问题：**"转型做交易员"这句话，具体是指哪条路？**
>
> 三条路的门槛、收入形态、失败模式完全不同。选错路比学错东西的代价大得多。

---

## 一、先说最重要的一句

> **"辞职全职做交易员"不是转型的起点，是转型的终点。**

原因：
1. 没有 track record 的自营交易，本质上是用生活费做高方差实验
2. 回撤期 + 没有现金流 = 执行纪律必然崩溃（这是最大的风险，不是策略风险）
3. 前 12 个月最可能的结果是"学到很多但没赚到钱"，这个阶段必须有别的收入支撑

**所以：先保住现金流，用业余时间把系统跑通并验证，再决定要不要全职。**

这不是保守，是让自己有足够多次尝试机会的唯一方式。量化是个需要多次迭代的手艺，一次押上全部就没有迭代机会了。

## 二、三条路对比

| | A. 自有资金自营 | B. 加入量化机构 | C. 管理外部资金 |
|---|---|---|---|
| **门槛** | 资金 + 策略 + 心理 | 面试硬门槛 | 合规 + track record |
| **收入形态** | 直接 PnL，高方差 | 薪资 + 分成，低方差 | 管理费 + carry |
| **起步时间** | 立即（小额） | 3-6 个月准备 | 2 年+ |
| **上限** | 受资金约束 | 受职级约束 | 高 |
| **对我的适配** | 中（资金是瓶颈） | **高** | 低（后期选项） |
| **主要失败模式** | 爆仓 / 回撤中放弃 | 面试失败 / 岗位不匹配 | 募不到资金 / 合规问题 |

### 我的判断：B 为主线，A 为验证

理由：
- **B 的适配度最高**：Crypto 交易所工程背景 + 10 年高并发 = QD（量化开发）方向的稀缺组合。见 [`06-engineering/00-README.md`](../06-engineering/00-README.md) 的分析
- **A 是必要的**：自己跑过实盘，才能在 B 的面试里说出真东西；也才知道自己是否真的适合交易
- **两者互相喂养**：机构工作提供现金流 + 见识 + 数据基础设施经验；自营验证提供实战理解
- **C 是可选的远期目标**：需要 2 年以上可验证 track record

## 四、一个诚实的自我评估

### 我的优势（可验证的）

| 优势 | 兑现路径 |
|---|---|
| 10 年+ 后端 / 高并发 / 分布式 | QD 岗位的核心要求 |
| CEX 业务与撮合侧经验 | 交易所/做市商/crypto 量化的稀缺背景 |
| Crypto 一线交易与链上经验 | crypto 量化团队的差异化优势 |
| 技术负责人经验（架构 + 团队） | 高级岗位、能带团队 |
| AI/Agent 工程落地 | 研究自动化、LLM 因子挖掘 |

### 我的差距（要诚实）

| 差距 | 补齐计划 |
|---|---|
| 统计/时间序列不系统 | [`00-foundations`](../00-foundations/)，3-4 周 |
| 没有量化研究的完整经验 | [`03-research-infra`](../03-research-infra/) + labs，4-6 周 |
| 没有实盘系统化交易记录 | 阶段三，小额实盘 60 天起 |
| C++/Rust 不熟 | 阶段四，或 QD 求职时提优先级 |
| 没有量化领域的公开作品 | labs 就是作品，边做边公开 |
| 没有量化圈人脉 | 通过开源、写作、社群积累 |

### 关键认知

**我的差距是"可以在 6 个月内明显缩小"的类型（工程化的知识补齐 + 实操积累），而不是"需要 3 年"的类型（如从零学数学）。**

而我的优势是"别人需要 10 年才能获得"的类型。这个不对称是我的机会所在。

## 五、时间线（与 ROADMAP 对齐）

```
月 1-2   打底：基础 + 微观结构 + 策略图谱
月 3-4   研究基础设施（我的强项，做深做扎实）
月 5-6   ML 方法论 + 模拟盘
月 7-8   小额实盘 + TCA + 第一份可展示的作品
月 9     ★ 决策点：评估 A/B 路径，是否启动 B 的求职
月 10-12 多策略组合 + （如走 B）简历与面试准备
```

### 第 9 个月的决策点

到那时会有真实数据支撑决策：
- 我的实盘系统跑得怎么样（在线率、错单、实盘-回测偏差）
- 我在回撤期的心理表现如何（交易日志里有记录）
- 我的学习速度如何（TRACKING.md 里有数据）
- 市场上 QD 岗位的实际要求（通过投递和面试摸清）

**用数据决策，不用感觉决策。** 这也是为什么 [`TRACKING.md`](../TRACKING.md) 和 [`journal/`](../journal/) 要认真填。

## 六、出口标准

1. 你选的是哪条路？为什么？放弃了什么？
