# 03 · 自营资金与心理规划

> 这一章讨论两件最不技术但最决定成败的事：**钱怎么分配，人怎么不崩。**
>
> 技术问题都有解法。资金分配错了和心理崩了，是不可逆的。

---

## 一、资金分层（先把钱分清）

```
总资产
├── 生活储备金（6-12 个月开支）      ← 绝对不动，不进任何交易账户
├── 长期配置（可选，被动持有）        ← 与交易策略隔离
└── 交易资金
    ├── 探索资金（可完全亏掉）        ← 阶段一到三只用这部分
    └── 核心交易资金（验证后逐步投入）
```

### 硬性规则

1. **生活储备金绝对不动**。这是你的心理底线，也是你能理性决策的前提。
2. **交易资金的定义**：亏光了不影响生活质量、不影响家庭关系、不需要向任何人解释。
3. **探索资金 ≤ 交易资金的 20%**，用于验证新策略。
4. **不借钱交易**。不用信用卡、不用杠杆贷款、不动房产。
5. **不用别人的钱**（在有正式 track record 和合规安排之前）。

### 探索资金的规模怎么定

关键不是"多少钱"，而是：

> **这笔钱亏光了，我明天还能正常工作、正常睡觉、正常和家人相处吗？**

如果答案是"不能"，就减半，再问一遍。

**反直觉但重要**：探索阶段的目标不是赚钱，是**收集真实数据**（系统稳定性、实盘偏差、自己的心理反应）。这些数据的价值远超小额资金的收益。用小钱买信息，是最划算的交易。

---

## 二、资金投入的阶梯

不要一次性投入。按验证进度分批：

| 阶段 | 条件 | 投入比例 |
|---|---|---|
| 模拟盘 | — | 0 |
| 极小额实盘 | 模拟盘 30 天无异常 | 探索资金的 20% |
| 小额实盘 | 极小额 30 天，实盘-回测偏差可解释 | 探索资金的 100% |
| 正式投入 | 小额实盘 60 天，PnL 归因清晰 | 核心资金的 20% |
| 逐步放大 | 每 3 个月评估一次，符合预期才加 | 每次 +20% |
| 满仓 | 累计 12 个月符合预期 | 核心资金的 100% |

### 放大的前提（必须全部满足）

- [ ] 系统在线率 > 99%
- [ ] 无未解释的实盘-回测偏差
- [ ] 无错单/状态不一致事件（或已修复且验证）
- [ ] 经历过至少一次显著回撤，且我的行为符合预设规则（没干预）
- [ ] 容量分析显示放大后不会显著衰减
- [ ] 我的心理状态稳定（交易日志能证明）

### 缩减的触发条件

- 触发策略级或账户级熔断
- 出现无法解释的偏差
- 我发现自己在频繁想干预
- 生活状况变化导致风险承受力下降

**"我发现自己在频繁想干预"这条很重要**：它是心理层面即将失控的早期信号，比 PnL 更早出现。

---

## 三、心理管理（最难的部分）

### 三个必须提前知道的事实

**1. 你会经历比回测更痛的回撤**

回测里的 20% 回撤是曲线上的一个凹陷。实盘里的 20% 回撤是连续几周每天早上醒来看到亏损。

对策：
- **提前知道自己策略的历史最大回撤和最长水下时长**（从 CPCV 的多条路径里取最差的）
- 用"这在正常范围内"的客观标准，而不是"感觉太糟了"

**2. 你会想干预，而干预大概率有害**

在最痛的时候，干预的冲动最强。而那个时刻往往正是策略即将恢复的时刻。

对策：
- **全自动执行**，减少介入机会
- **冷静期规则**：任何策略改动必须等 24 小时后执行
- 在交易日志里记录冲动（写下来，然后不做）
- 预先写下"什么情况下我会停"，并且只在那个条件触发时才停

**3. 顺利时你会想加杠杆**

连续盈利会让人高估自己的能力，低估尾部风险。而加杠杆的时点往往在收益均值回归之前。

对策：
- 杠杆规则写进配置文件，改动需要冷静期
- 定期重读 [`05-risk-and-portfolio/01-position-sizing-kelly.md`](../05-risk-and-portfolio/01-position-sizing-kelly.md) 里的波动率损耗算术

### 交易日志里必须记录情绪

```markdown
今日情绪：☐ 平静 ☐ 焦虑 ☐ 兴奋 ☐ 沮丧 ☐ 想干预
干预冲动：☐ 无 ☐ 想减仓 ☐ 想加仓 ☐ 想改参数 ☐ 想停策略
是否干预：☐ 否 ☐ 是（原因：___）
```

**为什么记录**：三个月后回看，你会发现自己的情绪模式，以及"如果当时干预了会怎样"。这是唯一能让你认识自己的方式。

模板见 [`journal/trade-journal-template.md`](../journal/trade-journal-template.md)。

### 关于"手动交易 vs 系统化交易"的心理差异

我有手动交易 crypto 的经验，但要注意：**系统化交易的心理挑战是不同的**。

| | 手动交易 | 系统化交易 |
|---|---|---|
| 控制感 | 高（每笔都是我决定的） | **低（系统在做，我只能看）** |
| 亏损归因 | "我判断错了" | "系统在亏，我该不该停？" |
| 主要挑战 | 冲动、贪婪、恐惧 | **无所作为的焦虑 + 干预冲动** |
| 需要的品质 | 判断力 | **纪律与耐心** |

**"看着系统亏钱而什么都不做"是一种全新的心理挑战。** 不要因为有手动交易经验就假设自己能扛住。

## 四、什么条件满足才考虑全职

这是 [`00-README.md`](./00-README.md) 出口标准第 5 题的答案。写出具体数字：

### 必要条件（全部满足）

- [ ] **连续 18 个月**的实盘记录（不是回测），且符合预期
- [ ] 经历过至少一次完整的回撤-恢复周期，行为符合规则
- [ ] 策略月收益（保守估计） ≥ 生活开支 × 2
- [ ] 有 24 个月的生活储备金（不在交易账户里）
- [ ] 多策略组合（≥ 3 个低相关策略），不依赖单一策略
- [ ] 系统能连续运行且我出差一周不用管
- [ ] 家庭知情并支持
- [ ] 有明确的失败退出方案（多久没达标就回去工作）

### 为什么标准这么高

因为全职的核心风险不是"策略失效"，而是：

> **没有现金流的情况下遇到回撤 → 心理压力 → 干预策略 → 破坏策略 → 更大亏损 → 恶性循环。**

**"生活开支 × 2"和"24 个月储备金"就是为了打断这个循环。** 它们让你在回撤期还能不慌。

### 一个更务实的中间态

不必二选一。中间态是：

```
主业保持（现金流）+ 系统化交易并行（不需要盯盘）
```

这个状态可以长期维持，而且：
- 有现金流 → 心理稳定 → 执行纪律好
- 交易资金持续增长 → 未来选择权变大
- 不需要赌上全部

**系统化交易的一大优势就是它不需要你全职。** 这一点值得反复提醒自己：全职做交易不是"更高级的阶段"，只是一种资金和时间的分配选择。

## 五、Track record 的规范记录（从第一天开始）

即使不打算走路 C（管理外部资金），规范记录的成本几乎为零，收益可能很大。

### 记录内容

| 项 | 频率 |
|---|---|
| 每日净值 | 每日 |
| 每笔交易明细（时间/标的/方向/数量/价格/费用） | 实时 |
| 持仓快照 | 每日 |
| 资金变动（入金/出金） | 事件 |
| 策略配置版本 | 变更时 |
| 异常事件与处理 | 事件 |
| 月度报告（收益/风险/归因） | 每月 |

### 提升可信度的做法

| 做法 | 价值 |
|---|---|
| 用交易所的 API 导出原始数据 | 可验证 |
| 净值曲线与交易所对账单一致 | 可审计 |
| 记录入出金，用时间加权收益率 | 正确的收益计算 |
| 公开（可选）：定期发布净值与月报 | 建立公信力 |
| 不修改历史记录 | **可信度的基础** |

**最后一条最重要**：一旦发现历史记录被修饰过，整个 track record 的价值归零。

## 六、动手清单

- [ ] 做资金分层，明确写下每一层的金额
- [ ] 确定探索资金规模（用"亏光了我还能正常生活吗"检验）
- [ ] 写下资金投入阶梯与每级的条件
- [ ] 写下放大与缩减的触发条件
- [ ] 从 CPCV 结果中提取"最差路径的回撤和水下时长"，记在显眼处
- [ ] 建立交易日志（含情绪记录）并开始每日填写
- [ ] 写下"什么情况下我会停掉策略"，配置化
- [ ] 写下"什么条件满足我才考虑全职"（用具体数字）
- [ ] 建立 track record 记录系统（每日净值 + 交易明细 + 月报）
- [ ] 与家人沟通计划与风险
- [ ] 设置日历提醒：每季度重读这一章

最后一条不是形式主义。**顺利时人会忘记风险，回撤时人会忘记规则。定期重读是唯一的对抗方式。**
