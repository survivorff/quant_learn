# notes · 笔记暂存

> 随手笔记、读书笔记、论文摘读、想法暂存。**低门槛区域** —— 不追求结构，先记下来。
>
> 与知识模块（`00-` 到 `07-`）的区别：那些是"沉淀过的结论"，这里是"原始材料"。

---

## 目录约定

```
notes/
├── README.md
├── books/          # 读书笔记（按书名）
├── papers/         # 论文摘读（按论文）
├── code/           # 源码阅读笔记（nautilus_trader 等）
├── strategies/     # 策略档案（用 strategy-card-template 填的）
└── ideas/          # 想法暂存（未验证）
```

## 各类笔记的模板

### 读书笔记（books/）

```markdown
# 书名 · 章节

## 一句话总结

## 我能直接用的 3 条
1.
2.
3.

## 与我已有认知冲突的地方

## 对应的代码产出
（在哪个 lab 里实现了什么）
```

**纪律**：每读完一章，要么产出代码，要么写下 3 条可操作结论。做不到说明没读懂，或者这章对我没用（也是有效信息）。

### 论文摘读（papers/）

见 [`resources/01-papers.md`](../resources/01-papers.md) 第七节的完整模板。核心是这一节：

```markdown
## 我能直接用的部分
（具体到"我要在哪个 lab 里实现什么"）
```

写不出来 = 这篇论文对我现在没用，记个结论就跳过。

### 源码阅读笔记（code/）

```markdown
# 项目名 · 模块

## 它解决什么问题

## 核心数据结构

## 一条完整链路的追踪
（如：一笔订单从创建到成交）

## 它怎么处理边界情况
（超时、拒单、部分成交）← 价值最大的一节

## 它的测试暴露了什么担忧

## 与我的实现的差异
| 方面 | 它 | 我 | 谁更好，为什么 |
|---|---|---|---|

## 我要改的地方
```

### 策略档案（strategies/）

用 [`02-strategy-zoo/strategy-card-template.md`](../02-strategy-zoo/strategy-card-template.md) 填。

**规则：任何策略进入回测前，先填这个档案。** "收益来源"和"失效条件"填不出来的，直接淘汰。

### 想法暂存（ideas/）

```markdown
# 想法：___

日期：
触发来源：（哪本书/哪次观察/哪个现象）

## 假设
（钱从谁手里赚，为什么他持续亏给我）

## 需要什么数据验证

## 预期符号
（在看结果之前写下来）

## 状态
☐ 未验证 ☐ 验证中 ☐ 已进策略档案 ☐ 淘汰（原因：___）
```

**"预期符号"这一栏是关键**：先写预期再看结果。如果结果与预期相反，那不是"发现了反向 alpha"，而是理解有问题 —— 否则就是在做曲线拟合。

## 一条纪律

> **想法是廉价的，验证是稀缺的。**
>
> 不要因为"想法很多"而兴奋。想法进入 `ideas/` 的成本是 5 分钟，进入策略档案的成本是几小时，进入实盘的成本是几周。
>
> **瓶颈永远在验证能力，不在想法数量。** 所以优先建流水线（[`labs/lab-03`](../labs/lab-03-factor-lab/)），而不是收集更多想法。
