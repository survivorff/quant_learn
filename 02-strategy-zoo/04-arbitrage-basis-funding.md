# 04 · 套利：期现、跨所、资金费

> **这是我优先级最高的策略族。** 理由：结构性收益来源 + crypto 独有 + 我懂交易所机制 + 低频不需要拼延迟。
>
> 但必须先破除一个幻觉：**这些都不是"无风险套利"。** 它们是"用尾部风险换取稳定收益"的交易。

---

## 一、资金费 Carry（现货-永续 delta 中性）

### 基本结构

```
现货买入 1 BTC  +  永续合约做空 1 BTC
→ delta ≈ 0，价格涨跌不影响（近似）
→ 收益 = 资金费收入 − 成本
```

资金费长期为正是常态（散户偏好做多加杠杆），所以做空永续方长期收取资金费。

### 收益计算（必须精确）

```
毛收益 = Σ(每期资金费率 × 名义仓位)
净收益 = 毛收益
        − 现货买入手续费
        − 永续开仓手续费
        − 现货卖出手续费（平仓）
        − 永续平仓手续费
        − 基差变动造成的实现损益
        − 资金占用的机会成本
        − 划转成本与时间成本
```

**关键**：如果持仓周期短，四次手续费可能吃掉几周的资金费收入。**这个策略需要足够长的持仓周期才有意义。**

### 真实风险清单（必须全部理解）

| 风险 | 说明 | 缓解 |
|---|---|---|
| **交易所对手方风险** | 交易所跑路/被黑/冻结提币，仓位归零 | 分散多所、限制单所敞口、定期提币演练 |
| **强平风险** | 永续空头保证金不足被强平，对冲失效变成裸多 | 用全仓/统一账户、保证金充足率监控、自动补保证金 |
| **资金费反向** | 极端行情下资金费转负，你从收钱变付钱 | 设置资金费阈值，转负持续则平仓 |
| **基差扩大** | 永续溢价扩大 → 空头浮亏 → 保证金压力（虽然最终会收敛） | 保证金留足够缓冲，不满仓 |
| **ADL 自动减仓** | 极端行情下你的盈利对冲腿被交易所强制减仓 | 无法完全避免，需监控保险基金状况 |
| **划转延迟** | 需要补保证金时资金转不过来 | 预留保证金缓冲，不依赖实时划转 |
| **借币成本**（如做空现货版本） | 借贷利率可能飙升 | 监控利率，设阈值 |
| **稳定币脱锚** | 保证金用的稳定币贬值 | 分散稳定币，或用 BTC 做保证金 |
| **手续费档位变化** | 成交量下降导致费率上升 | 计入保守档位 |

**最重要的一条**：这个策略的收益是"稳定的小额"，风险是"罕见的巨额"。**负偏分布**。所以杠杆必须极度保守，绝不能因为"看起来稳"而加杠杆。

### 实施要点

1. **保证金充足率是核心监控指标**，不是收益率
2. 用统一账户/全仓，让现货和空头仓位互相抵消风险
3. 设置自动补保证金和自动降杠杆逻辑
4. 记录每期资金费实收金额，与预期对比（交易所计算可能有细节差异）
5. 建立"平仓触发条件"：资金费低于阈值、基差异常、交易所异常

## 二、跨所价差套利

### 结构

同一资产在 A 所价格高于 B 所 → A 所卖 / B 所买。

### 两种模式

| 模式 | 做法 | 特点 |
|---|---|---|
| **搬砖（需转账）** | 在便宜的所买，转到贵的所卖 | 需要提币时间（分钟到小时），风险窗口大 |
| **双边持仓（不转账）** | 两所各持相反仓位，等价差回归再各自平掉 | **推荐**，不需要转账，但需要两所都有资金 |

双边持仓模式的逻辑：不追求"立即赚差价"，而是"等价差回归后平仓"。这本质上是配对交易（见 [`02-mean-reversion-statarb.md`](./02-mean-reversion-statarb.md)），且有可靠的收敛机制。

### 关键约束

| 约束 | 说明 |
|---|---|
| 资金分配 | 需要在多个所预置资金，资金效率降低 |
| 单腿风险（legging risk） | 一腿成交另一腿没成交 → 裸露敞口。用 FOK/IOC 或接受并快速处理 |
| 价差需覆盖双边成本 | 双边 taker 费 + 双边滑点，价差要足够大 |
| 交易所延迟差异 | 慢的所可能报价已过期 |
| 提币通道 | 即使不转账，长期也需要再平衡资金分布 |
| 小所风险 | 价差大的往往是小所，小所风险高（这是价差存在的原因之一） |

**核心洞察：价差大的地方风险也大。** 大价差通常意味着：小所、流动性差、提币受限、或者交易所本身有问题。这不是免费的钱，是风险补偿。

## 三、跨期与基差套利

如果交易所有交割合约（有明确到期日）：

```
远月合约溢价 → 做空远月 + 做多现货/近月
→ 到期必然收敛，收敛时点确定
```

**优势：收敛时点确定**，这比永续的"资金费机制锚定"更硬。

crypto 里交割合约不如永续活跃，但正因如此竞争少、基差可能更大。

年化收益计算：
```
年化 = (基差 / 现货价) × (365 / 到期天数)
```

## 四、三角套利与路径套利

在同一交易所内，通过多个交易对形成闭环：

```
USDT → BTC → ETH → USDT
如果闭环收益 > 三次手续费，存在套利
```

现实：
- 主流对上机会几乎瞬间消失（HFT 领地）
- 冷门对上偶有机会，但深度极浅，容量小
- **需要低延迟**，属于我的"不做清单"边缘

**判断：不作为主力策略。** 但可以作为一个监控指标 —— 三角套利机会持续存在，说明该所的做市不充分，其他策略也可能有机会。

## 五、链上-链下套利

CEX 与 DEX 的价差。

| 特点 | 说明 |
|---|---|
| 价差可能较大 | 尤其是新币、长尾币 |
| 受 gas 和 MEV 约束 | 链上腿的成本不确定 |
| 执行不确定 | 链上交易可能失败或被夹 |
| 需要链上工程能力 | 见 [`01-market-microstructure/04-mev-and-onchain-execution.md`](../01-market-microstructure/04-mev-and-onchain-execution.md) |

**我的判断**：这是我 crypto 经验能直接用上的地方，但竞争激烈（专业 MEV searcher）。可行的切入点是**长尾资产**和**较慢的价差**（不是抢单，而是等价差扩大到足够覆盖不确定性）。

## 六、套利策略的通用检查清单

上任何套利策略前，逐条核对：

- [ ] 我的收益来源是什么结构性机制？收敛机制是否明确？
- [ ] 双边（或多边）的**全部**成本算清了吗？（手续费×腿数、滑点、资金费、借贷、gas、提币费）
- [ ] 单腿风险怎么处理？如果一腿没成交，我的应急逻辑是什么？
- [ ] 强平风险：最坏情况下保证金够吗？压力测试跑了吗？
- [ ] 交易所风险：单个交易所敞口上限设了吗？
- [ ] 如果价差不收敛反而扩大，我的止损/退出条件是什么？
- [ ] 资金效率：这个策略占用多少资金，年化多少？值得吗？
- [ ] 容量上限是多少？
- [ ] 这个机会为什么还存在？（如果找不到理由，很可能是我算错了成本）

最后一条最重要。**如果一个套利机会看起来太好，99% 的可能是你漏算了某个成本或风险。**
