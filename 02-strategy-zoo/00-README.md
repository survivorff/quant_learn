# 02 · 策略图谱

> 通读这一章的目的**不是**为了挑一个策略去做，而是建立分类框架：知道每个策略族的收益来源、失效条件、容量上限。
>
> 判断一个人懂不懂量化，看他怎么描述策略：说"用 MACD 金叉买入"的是散户；说"这是一个中期时间序列动量策略，收益来源是投资者的处置效应和信息扩散的滞后，在震荡市失效，容量取决于标的流动性"的是量化。

## 一、策略档案模板（每个策略必须填）

任何策略进入研究流程前，先填这张表。填不出来的直接淘汰。

```markdown
## 策略名称

- **收益来源分类**：风险溢价 / 结构性错价 / 行为偏差 / 速度优势（选一个）
- **一句话逻辑**：钱从谁手里赚，他为什么持续亏给我
- **信号定义**：精确到能写成代码
- **持仓周期 / 换手率**：
- **失效条件**：什么情况下这个策略不该赚钱（必须写出来）
- **主要风险**：最坏情况长什么样
- **成本敏感度**：成本翻倍还赚钱吗
- **容量估计**：多少资金后开始衰减
- **拥挤度**：有多少人在做同样的事
- **实施难度**：数据 / 延迟 / 工程要求
- **对我的适配度**：高 / 中 / 低，为什么
```

模板文件见 [`strategy-card-template.md`](./strategy-card-template.md)。

## 三、按适配度排序的行动优先级

综合"收益来源可持续性 × 我的存量优势 × 实施门槛"：

```
优先级 1（先做）
├── 资金费 carry / 期现套利         ← 结构性、低频、我懂机制
└── crypto 场内价差均值回归         ← 现货-永续、跨所

优先级 2（并行研究）
├── 截面动量（选币）                 ← 经典、样本量够、容量大
└── 链上因子 + 清算级联反转          ← 我的差异化数据源

优先级 3（有余力再上）
├── 做市（先做模拟，理解库存风险）
└── 波动率策略（需要先补期权基础）

明确不做
└── 延迟套利、纯 HFT
```

## 四、出口标准

对下面每一条，能不看资料直接回答：

1. 趋势跟踪的收益分布长什么样？为什么它的胜率通常低于 50% 却能赚钱？
2. 配对交易最典型的死法是什么？怎么在事前防住？
3. 做市商的两大风险是什么？Avellaneda-Stoikov 模型是怎么处理它们的？
4. 资金费套利是不是无风险？列出至少 5 个真实风险。
5. 为什么"卖波动率"长期有正期望，它的风险分布长什么样？
6. 一个策略在回测里夏普 2.5，你要问哪 8 个问题才决定是否上实盘？

## 五、一条重要提醒：公开策略的处境

网上能搜到的策略（均线交叉、RSI 超买超卖、布林带、网格）在扣掉成本后基本都是负期望。这不是因为它们"不好"，而是因为：

1. **被广泛知道 = 被套利掉**
2. 大多数是**参数拟合的产物**，换个时段/标的就失效
3. 它们的"收益来源"说不清 —— 说不清就是没有

但它们有用途：**当作基线（baseline）**。你的新策略如果打不过"买入持有"和"简单均线"，那它没有价值。

**纪律：每个策略必须和三个基线对比**：
- 买入持有（buy & hold）
- 等权持有一篮子标的
- 一个最朴素的同类策略（如趋势策略对比简单均线）
