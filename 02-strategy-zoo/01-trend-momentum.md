# 01 · 趋势跟踪与动量

> 最古老、被最多独立研究验证、也最容易被误解的策略族。
>
> 核心特征：**低胜率、正偏收益分布、长期有效但会有多年的水下期。**

---

## 一、收益来源

趋势/动量的存在有多个互补解释（不是互斥的）：

| 解释 | 机制 |
|---|---|
| 信息扩散滞后 | 信息不是瞬间被所有人消化，价格分步反应 |
| 处置效应 | 投资者过早卖出盈利、过久持有亏损 → 抑制价格快速调整 |
| 羊群与反馈交易 | 追涨行为自我强化 |
| 风险溢价 | 趋势跟踪者提供了"承担持续性风险"的服务（在崩盘时反而赚钱，是一种保险的反面） |
| 机构资金流的惯性 | 大资金建仓需要时间，形成可预测的持续买压 |
| Crypto 特有：杠杆反馈 | 强平级联和杠杆增减放大趋势 |

**crypto 里趋势通常比传统市场更强**：市场更年轻、散户占比更高、叙事驱动、杠杆更普遍。但同时波动也大得多，风险调整后的优势不一定更好。

---

## 二、两种范式：时间序列 vs 截面

| | 时间序列动量（TSMOM） | 截面动量（XSMOM） |
|---|---|---|
| 逻辑 | 每个标的独立判断：涨了就做多 | 标的池内排序：做多最强、做空最弱 |
| 市场暴露 | 有（牛市满仓多头） | 近似中性（多空对冲） |
| 典型实现 | 均线/突破/回报符号 | 过去 N 期收益排名分组 |
| 危机表现 | **崩盘时转空，能赚钱**（危机 alpha） | 相对表现，与大盘无关 |
| crypto 适配 | 好（趋势明显） | 好（币种多，但要处理流动性和幸存者偏差） |

### 关键洞察

**这两个应该都做，因为它们的风险特征互补。** TSMOM 提供危机保护，XSMOM 提供市场中性的稳定收益。这是组合层面的分散化，比在单一策略里调参更有价值。

## 三、信号实现

### 时间序列动量的常见形式

| 形式 | 定义 | 备注 |
|---|---|---|
| 回报符号 | `sign(P_t / P_{t-N} − 1)` | 最朴素，作为基线 |
| 双均线交叉 | 快线 > 慢线 → 多 | 经典，但对参数敏感 |
| 突破（Donchian） | 突破 N 期最高价 → 多 | 海龟交易法的核心，稳健 |
| EWMAC | 不同半衰期的指数均线之差，再除以波动率标准化 | **推荐**：连续信号而非二值，可直接映射到仓位 |
| 时间序列动量 + 波动率标准化 | `r_{t-N:t} / σ` | 学术论文的标准做法 |

### 多周期组合（关键技巧）

单一参数的趋势策略对参数极度敏感。解法不是"找到最优参数"，而是**同时用多个周期并平均**：

```
信号 = 平均(EWMAC(8,32), EWMAC(16,64), EWMAC(32,128), EWMAC(64,256))
```

好处：
- 大幅降低过拟合风险（不需要选参数）
- 平滑信号，降低换手
- 不同周期捕捉不同的趋势尺度

**这是 Carver 在 *Systematic Trading* 里的核心方法，也是我最推荐的起手实现。**

### 波动率标准化（必做）

原始价格变化不可比：BTC 涨 1% 和某小币涨 1% 的风险完全不同。

```
标准化信号 = 原始信号 / 预测波动率
仓位 = 目标风险 × 标准化信号 / 当前波动率
```

这一步同时实现了：信号可比、仓位风险均衡、自动降低高波动时期的暴露。

## 四、截面动量的实现要点

```
1. 定义标的池（流动性筛选：日均成交量 > 阈值，上市 > N 天）
2. 计算每个标的过去 N 期收益（常用 20-90 天）
3. 可选：跳过最近 1 期（避免短期反转的污染）
4. 横截面排序 → 分成 5-10 组
5. 做多 top 组、做空 bottom 组，组内等权或按波动率倒数加权
6. 定期调仓（周/月），控制换手
```

### Crypto 截面动量的特殊问题

| 问题 | 处理 |
|---|---|
| **幸存者偏差** | 必须包含已下架/归零的币。只用现存币种会严重高估收益 |
| **流动性陷阱** | 排名靠前的往往是刚暴涨的小币，实际打不进去。必须按可交易性加权或设深度门槛 |
| **做空困难** | 很多小币没有永续合约，或借贷成本极高。纯多版本更现实 |
| **BTC beta 主导** | crypto 里第一主成分极强，截面收益可能只是"高 beta 币在牛市涨更多"。**必须做 beta 中性化** |
| **上币事件** | 新上币的价格行为异常，需要排除上市初期 |
| **代币经济变更** | 解锁、增发、销毁会造成非市场性的价格变动 |

**beta 中性化是必须的一步**：对每个币的收益回归 BTC 收益，用残差做动量排序。否则你测出来的"动量 alpha"实际上是"beta 暴露"。

## 五、风险与真实体验

### 收益分布特征

| 特征 | 数值感觉 |
|---|---|
| 胜率 | 通常 35%-45%（**低于 50%**） |
| 盈亏比 | 高（少数大赚覆盖多数小亏） |
| 偏度 | 正偏 |
| 最大回撤 | 可能相当大 |
| 水下时长 | **可能长达数年** |

### 心理层面的真实难度

这是趋势跟踪最被低估的成本：

- 大部分时间在小亏，赚钱集中在少数几段大趋势
- **如果你在水下期放弃，就必然亏钱** —— 因为你会系统性错过让你赚钱的那几段
- 震荡市里连续止损，会让你怀疑策略失效（但这正是趋势策略的正常状态）

**推论**：趋势策略的成功 90% 靠"不干预"的纪律，10% 靠信号质量。这也是为什么它必须系统化、自动化 —— 手动执行必然会在最痛的时候放弃。

### 主要失效条件

1. 长期震荡市（无持续方向）
2. 波动率剧烈变化时（vol targeting 会滞后）
3. 剧烈反转（V 型底，趋势信号在最低点做空）
4. 成本上升（换手太高时）
5. 标的相关性趋于 1（分散化失效，多个仓位同时亏）

## 六、我的实施计划

| 项 | 决定 |
|---|---|
| 优先实现 | 多周期 EWMAC + 波动率标准化 + 波动率目标仓位 |
| 标的池 | 主流永续合约（先 10-20 个流动性最好的） |
| 频率 | 日线信号，日内执行 |
| 第二步 | 加截面动量（beta 中性化后） |
| 基线对比 | 买入持有 BTC、等权持有 top 10 |
| 关键验证 | 多周期平均 vs 单一最优参数的样本外对比（验证"不选参数"更好） |
