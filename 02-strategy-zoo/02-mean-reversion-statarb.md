# 02 · 均值回归与统计套利

> 与趋势相反的收益分布：**高胜率、小赚、偶尔巨亏。** 这是"在压路机前捡钢镚"的典型形态。
>
> 关键区分：**有结构性锚定的均值回归**（现货-永续价差）远比**纯统计的均值回归**（两个不相关币的价差）可靠。

---

## 一、收益来源与关键前提

### 收益来源

| 类型 | 机制 | 可靠性 |
|---|---|---|
| 结构性锚定 | 同一标的的不同表现形式必然收敛（现货 vs 永续、跨所同一资产） | **高** |
| 流动性提供 | 短期供需失衡造成的偏离，你提供流动性收溢价 | 中高 |
| 过度反应 | 投资者对消息反应过度，随后修正 | 中 |
| 纯统计关系 | 历史上两个资产价差平稳 | **低**（关系可能只是巧合或已断裂） |

### 生死攸关的前提

均值回归策略赌的是"价差会回来"。**如果不会回来，你的亏损没有上限**（因为你在越亏越加）。

所以必须回答：
1. **为什么价差必须回归**（有没有结构性机制强制它回归）
2. **回归需要多久**（半衰期）
3. **如果不回归，我怎么知道，什么时候认输**

第 3 条最重要，也最容易被忽略。

---

## 二、按可靠性排序的机会（crypto）

### 层级 1：结构性锚定（最可靠，优先做）

| 机会 | 锚定机制 | 备注 |
|---|---|---|
| 现货 vs 永续基差 | 资金费机制强制锚定 | 见 [`04-arbitrage-basis-funding.md`](./04-arbitrage-basis-funding.md) |
| 同一资产跨所价差 | 可搬砖套利 → 必然收敛 | 受提币时间/成本约束 |
| 稳定币价差（同锚定资产） | 赎回机制 | 尾部风险是脱锚，需谨慎 |
| CEX vs DEX 价差 | 套利者会抹平 | 受 gas 和 MEV 约束 |
| 跨期合约价差（如有交割合约） | 到期收敛 | 确定的收敛时点是巨大优势 |

**这一层是我的主战场**：结构性、有明确收敛机制、我懂交易所内部逻辑。

### 层级 2：同类资产的相对价值

| 机会 | 逻辑 |
|---|---|
| 同生态代币（同一 L1 内的项目） | 共同暴露于生态基本面 |
| 同叙事板块内（如同类赛道） | 板块轮动的相对价值 |
| 主流币之间（BTC/ETH 比价） | 长期关系相对稳定，但会有制度性变化 |
| LST / 包装资产 vs 底层资产 | 有赎回锚定，但有流动性折价 |

### 层级 3：纯统计配对（最不可靠）

用协整检验找出的"历史上价差平稳"的币对。

**crypto 里这一层非常危险**：
- 项目基本面变化快，历史关系随时断裂
- 数据历史短，协整检验的统计功效低
- 大量币对 → 严重的多重检验问题（测 1000 对必然找到"显著协整"的）

**如果要做，必须**：滚动重新检验协整、设硬止损、设最长持仓时间、严格限制仓位。

## 三、配对交易的完整流程

```
1. 候选筛选：同类别、流动性达标、历史长度足够
2. 协整检验：Engle-Granger 或 Johansen，得到对冲比率 β
3. 构造价差：spread = log(P_A) − β·log(P_B)
4. 估计 OU 参数：得到均值 μ、回归速度 θ、波动 σ
5. 计算半衰期：ln(2)/θ → 判断是否适合你的持仓周期
6. 标准化：z = (spread − μ_rolling) / σ_rolling   ← 必须用滚动窗口，不能用全样本
7. 交易规则：z > +2 做空价差；z < −2 做多价差；|z| < 0.5 平仓
8. 风控：|z| > 4 强制止损（假设关系已断裂）+ 最长持仓时间限制
9. 定期重新检验协整，失效则退出
```

### 每一步的坑

| 步骤 | 坑 |
|---|---|
| 对冲比率 β | 用全样本 OLS 估计 = 未来函数。必须滚动估计，或用 Kalman 滤波动态跟踪 |
| 标准化 | 用全样本均值方差 = 未来函数。必须滚动 |
| 阈值选择 | ±2 是习惯值不是真理。用参数扫描找最优 = 过拟合。**建议固定用 ±2，不调** |
| 半衰期 | 如果半衰期比你的持仓耐受期长，这个配对不适合你，不管回测多好 |
| 止损 | 均值回归策略的止损很反直觉（越亏越应该加仓才对），但**没有止损就是无限风险** |
| 多重检验 | 筛选 N 个配对必须做 FDR 或 DSR 修正 |

### 关于"越亏越加"的悖论

均值回归的数学逻辑说：z 越大，预期收益越高，应该加仓。
风险管理说：亏损放大说明假设可能错了，应该减仓。

**实务解法**：
- 分批建仓（z=2 建 1/3，z=3 建 2/3，z=4 满仓）
- 但设**绝对上限**（z=4 之后不再加，z=5 强制止损离场）
- 单个配对的最大仓位硬约束（不管信号多强）

这是"接受偶尔认错的成本，换取不会爆仓"的交换。

## 四、统计套利（多资产版本）

比配对交易更进一步：用因子模型剥离系统性风险，对残差做均值回归。

```
1. 对标的池做 PCA 或用因子模型（市场 beta、板块因子）
2. 计算每个标的的残差收益（去掉系统性部分）
3. 对残差做累积，得到"残差偏离度"
4. 做多残差最负的、做空残差最正的
5. 组合层面做风险约束（板块中性、beta 中性、单标的上限）
```

优点：
- 天然分散（几十个标的而非一对）
- 系统性风险被剥离，收益更纯
- 单个标的关系断裂不致命

缺点：
- 需要更多标的和更好的数据
- 换手率高 → 成本敏感
- 拥挤度高（这是机构 statarb 的主战场）

**crypto 版的现实**：PCA 第一主成分（BTC beta）解释力极强，去掉它之后残差信噪比不高，且需要大量标的。可以做，但预期不要太高。

## 五、日内均值回归

短周期（分钟-小时）的反转，收益来源是流动性提供。

关键要素：
- 信号：短期极端价格变动 + 订单簿失衡 + 成交量异常
- **必须做 maker**：这类策略在 taker 费率下必死
- 成本是绝对的生死线：见 [`01-market-microstructure/02-execution-costs-and-slippage.md`](../01-market-microstructure/02-execution-costs-and-slippage.md)
- 注意 bid-ask bounce 造成的虚假反转信号（用中间价，不用成交价）

**清算级联反转**是 crypto 里日内均值回归最有逻辑的版本：强平抛压是非信息性的，价格偏离是机械性的，因此回归概率高。详见 [`06-crypto-native-strategies.md`](./06-crypto-native-strategies.md)。

## 六、风险特征（必须内化）

| 特征 | 说明 |
|---|---|
| 胜率 | 高（60%-80%） |
| 盈亏比 | 低 |
| 偏度 | **负偏** —— 少数大亏吃掉多数小赚 |
| 最坏情况 | 关系断裂 + 杠杆 = 爆仓 |
| 与趋势策略的相关性 | 负相关 —— **这是组合层面的核心价值** |

### 典型死法

1. **关系断裂**：配对的一方基本面永久改变（项目出事、被下架、代币经济变更）
2. **杠杆放大**：因为"胜率高"而上高杠杆，一次断裂全部还回去
3. **拥挤平仓**：大家同时做同一个价差，一起被迫平仓时价差反而扩大
4. **流动性消失**：想平仓时对手方不在了
5. **成本吞噬**：高换手 + 未充分建模的成本

### 与趋势策略配对的价值

趋势策略：低胜率、正偏、震荡市亏钱
均值回归：高胜率、负偏、趋势市亏钱

**两者组合的夏普通常显著高于任一单独策略。** 这比在单一策略里优化参数的收益大得多，也是我在 `ROADMAP.md` 阶段四要做的事。
