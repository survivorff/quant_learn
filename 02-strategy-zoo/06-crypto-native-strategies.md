# 06 · Crypto 原生策略

> **这是我的差异化区。** 传统 quant 有更好的数学，但他们没有链上数据的直觉，也不理解交易所机制的细节。
>
> 这一章的策略都有一个共同点：**只在 crypto 存在，且需要 crypto 领域知识才能做对。**

## 一、清算级联反转

### 逻辑

强平抛压是**被迫的、非信息性的、机械性的**。价格因此产生的偏离没有信息含量，所以有回归倾向。

这是"行为偏差 + 结构性"的混合机会，逻辑链条清晰：

```
高杠杆多头拥挤（高 OI + 高资金费）
  → 价格下跌触发强平
  → 强平引擎抛售推动价格进一步下跌
  → 触发更多强平（级联）
  → 短时间极端偏离
  → 抛压出清后快速回归
```

### 信号构造

**事前（拥挤度）**：
| 特征 | 含义 |
|---|---|
| OI / 市值 比率 | 杠杆水平 |
| 资金费率水平与持续时间 | 多空拥挤方向与程度 |
| 多空持仓比 | 方向失衡 |
| OI 增长速度 | 新杠杆涌入速度 |
| 距离主要清算价位的距离 | 触发难度（部分平台有清算热力图数据） |

**事中（级联识别）**：
| 特征 | 数据来源 |
|---|---|
| 强平订单流 | 交易所强平推送频道 |
| OI 骤降幅度 | OI 时间序列 |
| 单向连续大额吃单 | 逐笔成交（taker 方向） |
| 深度瞬间抽空 | L2 深度快照 |
| 价格偏离标记价/指数价 | 标记价 vs 成交价 |

**事后（入场）**：
- 在级联的极端偏离处挂限价单接盘
- 或在级联结束确认后（强平流量衰减 + OI 稳定）入场

### 风险（必须正视）

| 风险 | 说明 |
|---|---|
| 分不清"级联"和"真实崩盘" | 如果是基本面驱动的趋势性下跌，接盘会一路亏 |
| 二次级联 | 第一波之后可能还有第二波 |
| 收益分布负偏 | 多次小赚 + 偶尔大亏 |
| 需要极快的数据与执行 | 极端行情持续时间可能很短 |
| 交易所在极端行情可能拒单/限流 | 你可能根本下不进单 |

**必须有的约束**：硬止损、单笔仓位上限、最大连续加仓次数、日内亏损熔断。

## 二、资金费/OI 作为情绪与拥挤度因子

即使不做 carry 套利，资金费和 OI 也是**高质量的情绪数据**，可以作为特征喂给其他策略。

| 因子 | 构造 | 假设的方向 |
|---|---|---|
| 资金费 z-score | 相对历史分布的极端程度 | 极端正 → 多头拥挤 → 短期反转风险 |
| 资金费动量 | 变化率 | 情绪加速 |
| OI 变化 × 价格变化 | 四象限分析 | 价涨 OI 涨 = 新多进场；价涨 OI 跌 = 空头平仓（弱） |
| 多空比极值 | 相对历史分位 | 拥挤度 |
| 跨所资金费分歧 | 不同所的费率差 | 分歧大 = 结构性失衡 |

**OI 与价格的四象限分析**（经典但有效）：

| 价格 | OI | 解读 |
|---|---|---|
| ↑ | ↑ | 新资金做多，趋势较健康 |
| ↑ | ↓ | 空头平仓推动，上涨动能弱 |
| ↓ | ↑ | 新资金做空，下跌趋势较强 |
| ↓ | ↓ | 多头平仓/强平，可能接近尾声 |

**这些数据完全免费，且传统 quant 不熟悉。这是低垂的果实。**

## 三、链上数据因子

crypto 独有的替代数据。全量历史公开可查，成本几乎为零。

### 因子分类

| 类别 | 具体指标 | 假设 |
|---|---|---|
| **资金流** | 交易所净流入/流出、稳定币铸造与销毁、桥资金流 | 流入交易所 = 潜在卖压 |
| **持币结构** | 大额地址持仓变化、持币时长分布、集中度 | 巨鲸行为领先 |
| **智能资金** | 历史胜率高的地址的行为 | 跟随聪明钱 |
| **网络活动** | 活跃地址数、交易数、手续费收入 | 真实使用度 |
| **协议数据** | TVL、借贷利用率、清算量 | 杠杆与风险水平 |
| **供给事件** | 代币解锁日历、增发/销毁、质押解锁 | 可预测的供给冲击 |
| **DEX 数据** | 流动性深度变化、新池创建、异常交易 | 早期信号 |

### 关键挑战

| 挑战 | 说明 |
|---|---|
| 地址聚类 | 一个实体有多个地址，需要启发式聚类，容易出错 |
| **交易所地址标注** | 标注质量决定资金流指标质量。标注是滞后的且不完整 |
| 内部转账噪声 | 交易所内部归集/冷热钱包转移会污染"流入"指标 |
| Point-in-time 正确性 | 地址标签是**今天**的知识，用在历史回测上就是未来函数。**这是链上因子最大的陷阱** |
| 链重组 | 短期数据可能回滚 |
| 多链碎片化 | 同一资产在多链上，需要合并视图 |
| 数据量 | 全量链上数据极大，需要合理的存储与索引 |

### PIT 陷阱的具体例子

你今天知道地址 X 是某交易所的钱包。但在 2 年前，没人知道这一点。如果你用今天的标签去回测 2 年前的"交易所净流入"因子，你在使用当时不可得的信息 —— 这是隐蔽但严重的未来函数。

**对策**：使用带时间戳的标签快照，或者只用不依赖标注的指标（如活跃地址数、大额转账笔数）。

## 四、事件驱动策略

crypto 的事件比传统市场更频繁、更可预测：

| 事件 | 可交易性 | 备注 |
|---|---|---|
| 上币公告 | 高（有明确的公告-上线时间差） | 竞争激烈，速度要求高 |
| 下架公告 | 中 | 流动性会恶化 |
| 代币解锁 | 高（日历完全公开） | 供给冲击可预测，但市场也知道 |
| 空投与快照 | 中 | 快照前买入、快照后卖出的模式 |
| 分叉 / 升级 | 中 | 需要技术判断 |
| 指数纳入/剔除 | 中 | 被动资金流 |
| 解锁质押 / 提款开启 | 中 | 潜在卖压 |
| 监管消息 | 低（不可预测） | 只能反应，不能预测 |

### 研究方法

用**事件研究法（event study）**：
1. 定义事件与时间戳（必须精确，且是"公告时刻"不是"生效时刻"）
2. 计算事件前后 N 期的异常收益（相对 BTC 或板块基准）
3. 对多个同类事件求平均，看是否有系统性模式
4. 检验统计显著性与稳健性（分时段、分市值）

**关键**：必须用公告的精确时间戳。用"日期"而不是"时刻"会引入严重的未来函数。

## 五、LP 与收益策略

提供流动性本质上是"卖波动率 + 做市"的混合体。

| 策略 | 逻辑 | 主要风险 |
|---|---|---|
| 稳定币对 LP | 低无常损失，赚手续费 | 脱锚风险、智能合约风险 |
| 集中流动性主动管理 | 在窄区间提供流动性，资金效率高 | 需频繁调整区间，gas 成本高；本质是主动做市 |
| 波动对 LP + delta 对冲 | LP 收手续费，用永续对冲 delta | 对冲误差、gamma 暴露（LP 是负 gamma） |
| 借贷利率套利 | 不同协议间的利率差 | 智能合约、清算、利率突变 |

### LP 的本质

**LP 头寸 ≈ 卖出了一个跨式期权。** 你的收益是手续费（类似 theta），风险是价格大幅变动（负 gamma）。

这意味着：
- 手续费收入必须补偿波动率风险，否则 LP 是负期望
- 判断 LP 是否值得，等价于判断"隐含的手续费年化率 vs 实际波动率"
- 高波动 + 低手续费 = 必亏

**这个视角能立刻筛掉大部分看起来 APY 很高的 LP 机会。**

### 智能合约风险

无法用金融手段对冲。只能：
- 只用经过长期验证的主流协议
- 分散到多个协议
- 限制单协议敞口
- 认真读审计报告，但不迷信它

## 六、Meme / 长尾资产

我有这块的一线经验。诚实评估其量化可行性：

| 特点 | 影响 |
|---|---|
| 极高波动、极短生命周期 | 统计规律不稳定，样本外泛化极差 |
| 流动性极浅 | 容量极小，滑点巨大 |
| 大量归零 | 严重的幸存者偏差，回测几乎必然虚高 |
| MEV / 抢跑严重 | 执行成本不可预测 |
| 有 rug pull（跑路）风险 | 非市场风险，无法用统计建模 |
| 但：链上信号丰富 | 早期买入地址、部署者行为、流动性锁定状态可查 |

**判断**：
- ❌ 不适合作为**主力**量化策略（容量太小、尾部风险不可控、回测不可信）
- ✅ 可以作为**小额、独立、限亏**的探索性策略池
- ✅ 链上早期信号的**研究价值高**（学会怎么处理这类数据，方法可迁移）
- ✅ 作为"链上数据管道"的练手对象很合适

**如果做，硬约束**：单独的小额账户、总额上限、单笔上限、亏光了就是亏光了（不追加），且不影响主策略资金。
