# 05 · 期权与波动率

> 定位：**阶段三之后的选项**。门槛最高，但也是"结构性机会最多、竞争相对少"的领域，尤其在 crypto。
>
> 核心认知：期权交易的是**二维的**（价格 × 波动率），而线性产品只有一维。这既是复杂性来源，也是机会来源。

---

## 一、为什么值得学（即使不马上做）

1. **卖波动率是最扎实的风险溢价之一**：隐含波动率长期高于实际波动率（波动率风险溢价），这是有经济基础的 —— 买保险的人愿意付溢价。
2. **crypto 期权市场相对不成熟**：定价效率低于传统市场，结构性机会更多。
3. **理解期权能改善其他策略**：任何带止损的策略本质上有期权特征；永续的资金费与波动率相关；理解 gamma 能让你理解为什么某些价位有"磁性"。
4. **对冲工具**：用期权保护尾部风险，比单纯止损更可控。

---

## 二、必须掌握的概念

### 希腊字母

| 字母 | 含义 | 交易上的意义 |
|---|---|---|
| Delta (Δ) | 对标的价格的一阶敏感度 | 方向暴露；delta 中性 = 不赌方向 |
| Gamma (Γ) | Delta 的变化率 | 正 gamma = 涨跌都赚（但要付 theta）；负 gamma = 涨跌都亏 |
| Theta (Θ) | 时间衰减 | 卖方每天收 theta，买方每天付 theta |
| Vega (ν) | 对隐含波动率的敏感度 | 赌波动率本身 |
| Rho (ρ) | 对利率的敏感度 | crypto 里主要体现为资金费/借贷利率 |

### 最重要的一组关系

```
买期权 = 正 gamma + 负 theta   （赌大波动，付时间成本）
卖期权 = 负 gamma + 正 theta   （赌小波动，收时间成本）
```

**这就是期权交易的核心张力**：你要么"付钱赌波动"，要么"收钱赌平静"。

### 隐含波动率（IV）与实际波动率（RV）

| 概念 | 定义 |
|---|---|
| 隐含波动率 | 从期权价格反推出的市场预期波动率 |
| 实际/已实现波动率 | 从历史价格算出的真实波动率 |
| **波动率风险溢价（VRP）** | IV − RV，长期为正 |
| 波动率曲面 | IV 随行权价（skew/smile）和到期日（term structure）的变化 |

**VRP 长期为正是"卖波动率"策略的收益来源。** 但它的分布是极端负偏的：长期小赚，偶尔巨亏（因为你在卖保险）。

### 波动率曲面的结构

| 维度 | 现象 | 含义 |
|---|---|---|
| Skew（偏斜） | 股票市场看跌期权 IV 更高（怕跌）；**crypto 有时相反（怕暴涨）** | 反映市场对哪个方向的尾部更恐惧 |
| Smile（微笑） | 深度价内外 IV 高于平值 | 市场承认厚尾（Black-Scholes 假设的正态不成立） |
| Term structure（期限结构） | 通常近月 IV 低于远月（正常态）；恐慌时倒挂 | 倒挂是压力信号 |

**crypto 的 skew 方向会切换**，这本身是一个情绪指标 —— 值得作为因子研究。

## 三、定价模型

### Black-Scholes（起点，不是终点）

必须理解它，但更要理解它**错在哪**：

| 假设 | 现实 | 后果 |
|---|---|---|
| 收益率正态分布 | 厚尾 | 低估尾部期权价值 → smile 的来源 |
| 波动率恒定 | 波动率随机且聚集 | 需要随机波动率模型 |
| 可连续对冲 | 离散对冲有误差 | 实际对冲成本高于理论 |
| 无交易成本 | 有 | 削减策略收益 |
| 无跳跃 | crypto 经常跳 | 跳跃风险无法用 delta 对冲 |

### 更现实的模型

| 模型 | 解决什么 |
|---|---|
| 局部波动率（Dupire） | 拟合当前曲面 |
| 随机波动率（Heston、SABR） | 波动率本身随机，能生成 smile |
| 跳跃扩散（Merton、Bates） | 显式建模跳跃 |
| 粗糙波动率（rough volatility） | 更好地拟合波动率的粗糙路径特性 |

**实务态度**：模型是用来插值曲面和计算希腊字母的工具，不是用来"找到真实价格"的。做交易靠的是相对价值判断和风险管理，不是精确定价。

## 四、策略族

| 策略 | 结构 | 赌什么 | 风险 |
|---|---|---|---|
| Covered call | 持币 + 卖看涨 | 小幅上涨/横盘 | 放弃大涨收益 |
| Cash-secured put | 现金 + 卖看跌 | 不跌破行权价 | 下跌时被迫买入 |
| **卖跨式/宽跨式** | 同时卖看涨看跌 | 波动率下降/横盘 | **无限风险，必须严格风控** |
| 买跨式/宽跨式 | 同时买看涨看跌 | 大波动（方向无所谓） | 时间衰减吃掉本金 |
| Calendar spread | 买卖不同到期 | 期限结构变化 | vega 与 theta 的复合 |
| Vertical spread | 买卖不同行权价 | 有限方向 + 有限风险 | 收益也有限 |
| Gamma scalping | 买期权 + 动态 delta 对冲 | RV > IV | 对冲成本、执行 |
| Vol arbitrage | 判断 IV 错价，做多/空 vega 并对冲 delta | IV 回归 | 模型风险、对冲误差 |
| Risk reversal | 买一边卖另一边 | Skew 变化 | 方向暴露 |

### Gamma scalping 值得单独说

这是最"纯粹"的波动率交易：
1. 买入期权（获得正 gamma）
2. 持续做 delta 对冲（价格涨就卖标的，跌就买标的）
3. 对冲动作在价格波动中"低买高卖"，赚取的就是实际波动
4. 如果 **实现波动 > 隐含波动**，对冲收益 > 付出的 theta，净赚

反过来卖期权 + 对冲，就是赌 IV > RV（收 VRP）。

**为什么这个策略有教育价值**：它把"波动率"从抽象概念变成可操作的现金流，是理解期权本质的最好方式。

## 五、Crypto 期权的现实

| 方面 | 情况 |
|---|---|
| 流动性 | 集中在少数交易所，BTC/ETH 为主，其他标的极浅 |
| 主要期限 | 短期为主（日/周），长期流动性差 |
| 结算 | 通常币本位或 USDT 本位，注意结算币种带来的额外风险 |
| IV 水平 | 远高于传统市场 |
| Skew 特征 | 会在"怕跌"和"怕涨"之间切换 —— 这是 crypto 独有的信号 |
| 买卖价差 | 宽，成本高，影响策略可行性 |
| 数据 | 部分交易所提供历史期权数据，需要自己整理曲面 |
| 链上期权协议 | 存在但流动性有限，机制各异 |

### 现实的入手方式

1. **先只做数据研究**：构建 IV 曲面，统计 VRP（IV − 后续实现 RV），验证它是否长期为正
2. **理解 skew 与市场事件的关系**：把 skew 当作情绪因子，用在**其他策略**上（这个不需要交易期权就能做，价值很高）
3. **小规模尝试有限风险结构**（vertical spread，风险有上限）
4. **绝不裸卖期权**，除非有完整的希腊字母监控和保证金压力测试

### 硬性警告

**裸卖期权是个人交易者最常见的爆仓方式。** 卖跨式在 95% 的时间里每天赚钱，然后一次极端行情把两年的收益还回去还倒欠。crypto 的尾部比股票厚得多，这个风险被系统性低估。

如果做卖方，必须：
- 用价差结构限定最大损失（不裸卖）
- 仓位极小
- 有明确的 gamma/vega 暴露上限
- 做极端场景压力测试（标的 ±50% 会怎样）

## 六、动手清单

- [ ] 实现 Black-Scholes 定价与希腊字母计算，验证 put-call parity
- [ ] 从交易所拉期权数据，构建 IV 曲面，可视化 skew 与期限结构
- [ ] 统计 VRP：对比 IV 与后续实际实现波动率，看长期是否为正、分布如何
- [ ] 统计 crypto skew 的历史变化，找出它与后续价格行为的关系（当作因子测 IC）
- [ ] 模拟 gamma scalping：买入期权 + 离散 delta 对冲，测量对冲频率对结果的影响
- [ ] 对一个卖跨式仓位做压力测试：标的 ±20%/±50%，波动率翻倍，看损失
- [ ] 把 IV 或 skew 作为特征加入趋势/均值回归策略，看是否提升（**最实用的一步**）
