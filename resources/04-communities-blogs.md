# 社区、博客与持续输入

> 量化领域信息噪声比极高。这一页的重点不是"关注更多"，而是**建立过滤机制**。
>
> 原则：**宁可少看，不要看错。** 看错的信息会让你浪费几个月。

---

## 一、信息源的质量分级

| 等级 | 特征 | 例子 |
|---|---|---|
| **A：一手资料** | 原始、可验证 | 交易所 API 文档、论文原文、开源源码、链上数据 |
| **B：从业者的技术输出** | 有实操细节、承认局限 | 量化机构的公开研究、开源作者的博客、技术会议分享 |
| **C：教育性内容** | 概念正确但缺细节 | 教科书类博客、入门教程 |
| **D：营销内容** | 有商业动机 | 卖课、卖信号、卖机器人 |
| **E：噪声** | 收益截图、"必赚策略" | 大部分社媒内容 |

### 我的时间分配规则

```
A 级：70%    ← 主要时间
B 级：25%
C 级：5%
D/E 级：0%   ← 不看
```

**这个分配是反直觉的**：大多数人花 80% 时间在 C-E 级内容上，因为它们更容易消费。但 A 级才是真正的信息来源。

---

## 二、判断内容质量的快速标准

看到任何量化内容，先问这几个问题：

| 问题 | 不合格的信号 |
|---|---|
| 有没有说明成本假设？ | 完全不提手续费/滑点 → 可信度大降 |
| 有没有基线对比？ | 只报绝对收益，不和买入持有比 |
| 有没有报告回撤和水下时长？ | 只报收益率 |
| 有没有说试了多少次？ | 直接给出"最优参数" |
| 有没有说明失效条件？ | 声称"永远有效" |
| 有没有承认局限？ | 通篇都是优点 |
| 是不是在卖东西？ | 结尾有付费链接 |

### 一条最简单的过滤器

> **任何展示收益曲线但不展示回撤和成本假设的内容，直接跳过。**

这一条能过滤掉 90% 的噪声。

## 三、值得关注的内容类型

### 高价值

| 类型 | 为什么 |
|---|---|
| **开源项目的 issue 和 PR 讨论** | 真实问题的真实讨论，无营销动机 |
| 开源作者的设计文档 | 讲清了取舍 |
| 量化机构的公开研究报告 | 有数据、有方法 |
| 交易所的技术博客与公告 | 一手的机制变更信息 |
| 学术论文（按 [`01-papers.md`](./01-papers.md) 的标准筛选） | 方法论 |
| 从业者的"失败复盘"类分享 | **比成功案例价值高**（失败原因更有普适性） |
| 链上数据平台的公开 query | 学别人怎么定义指标 |

### 低价值（不看）

| 类型 |
|---|
| 收益截图 |
| "月入 X 万的量化策略" |
| 卖信号 / 带单 / 现成机器人 |
| 无成本假设的回测分享 |
| 短视频形式的"策略教学" |

## 四、社区参与的正确方式

### 目的

不是"获取策略"（有效策略不会公开），而是：

| 目的 | 做法 |
|---|---|
| 了解生态变化 | 关注交易所机制变更、新产品、监管 |
| 技术问题求助 | 具体的工程问题（如 WS 订单簿维护） |
| 建立人脉 | 为路径 B（求职）铺路 |
| 输出与反馈 | 发布自己的开源作品，收集反馈 |

### 参与原则

1. **贡献先于索取**：先输出有价值的内容，再提问
2. **不要问"什么策略能赚钱"**：没人会告诉你，问了也降低自己的可信度
3. **问具体的技术问题**：这类问题有人愿意答
4. **不要分享自己的实盘细节**：参数、资金规模、具体持仓
5. **警惕"私聊你"的人**：大概率是骗局

公开输出的价值：建立可信度 + 强迫自己想清楚 + 为求职铺路。

### 短期（有作品后）

| 开源 lab-02 回测框架 | 完成后 | 工程作品 |

| "交易系统的幂等与对账"技术文 | lab-05 完成后 | 展示我的后端优势 |

### 中期

| 内容 | 价值 |
|---|---|
| 读书/论文笔记系列 | 持续输出，低成本 |
| nautilus_trader 源码解析 | 深度 + 对社区有贡献 |
| Rust 订单簿实现的技术文 | 阶段四，QD 求职筹码 |

### 输出纪律

| 规则 | 原因 |
|---|---|
| **不公开具体有效因子** | 会被套利掉 |
| **不公开实盘参数与资金规模** | 安全 + 隐私 |
| **不承诺收益** | 合规 + 诚信 |
| **诚实说明局限** | 长期可信度 |
| 公开工程能力和方法论 | 这是资产不是负债 |

**核心逻辑（重申）**：工程能力公开是资产，具体 alpha 公开是负债。

## 六、防骗提醒（crypto 领域尤其重要）

| 骗局类型 | 识别 |
|---|---|
| 卖信号 / 带单 | 如果真能赚钱，为什么要卖信号 |
| 现成"量化机器人" | 通常是网格/马丁格尔，数学上保证爆仓 |
| "帮你管理资金" | 无托管、无审计 = 资金归零风险 |
| 高收益理财 / 挖矿 | 庞氏结构 |
| 假交易所 / 假 App | 只用官方渠道 |
| 钓鱼网站 / 假空投 | 检查域名；不签授权 |
| "内部消息" | 100% 是骗局 |
| 冒充招聘的钓鱼 | 不点不明链接，不安装不明软件 |

### 硬性规则

1. **不给任何人转账/授权**
2. **不在不明网站连接钱包**
3. **不安装不明软件**（尤其是"量化交易软件"）
4. **不把 API key 给任何第三方**
5. **不相信任何收益承诺**

## 七、每周的信息摄入预算

避免"学习成瘾"（看资料的快感替代了动手的痛苦）：

```
每周信息摄入 ≤ 2 小时
每周动手时间 ≥ 6 小时
```

**比例 1:3。** 如果这个比例反了，说明我在逃避动手。

这条在 [`TRACKING.md`](../TRACKING.md) 里可以量化追踪。

---

## 八、一条元建议

> **当你不知道该学什么的时候，答案永远是"去写代码"。**
>
> 信息焦虑的解法不是看更多资料，是让手上的 lab 往前推进一步。被卡住之后，你自然会知道该学什么 —— 而那时的学习效率是漫无目的浏览的十倍。
