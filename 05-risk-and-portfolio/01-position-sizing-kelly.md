# 01 · 仓位管理

> **仓位决定生死，信号只决定方向。**
>
> 同一个信号，仓位放大 3 倍不是收益放大 3 倍，而是"收益放大 3 倍 + 破产概率放大很多倍"。这个非对称性是这一章的全部内容。

---

## 一、为什么仓位比信号重要

### 波动率损耗的算术

几何收益 ≈ 算术收益 − σ²/2

假设一个策略算术期望年化 20%，波动率 40%：
- 1 倍杠杆：几何收益 ≈ 20% − 0.4²/2 = 12%
- 2 倍杠杆：算术 40%，波动 80% → 几何 ≈ 40% − 0.8²/2 = 8%
- 3 倍杠杆：算术 60%，波动 120% → 几何 ≈ 60% − 1.2²/2 = -12% **（负的）**

**加杠杆到一定程度，长期收益反而下降，最后变负。** 这是数学必然，不是运气问题。

这个计算是本章最重要的一段。它意味着：**存在一个最优杠杆，超过它就是在自我伤害。**

### 破产概率

即使期望为正，仓位过大也会因为路径依赖而归零。50% 的仓位遇到 50% 的下跌就是 25% 的损失；100% 仓位加 2 倍杠杆遇到 50% 下跌就是归零。

**归零是不可逆的。** 这就是为什么风控是非对称的：上行的收益是线性的，下行的破产是终局的。

## 二、Kelly 公式

### 核心思想

最大化**长期对数财富增长率**（而不是期望收益）。

对于连续型收益（正态近似）：

```
f* = μ / σ²
```

其中 μ 是超额期望收益，σ² 是方差。

**这个公式说：最优杠杆 = 夏普比率 / 波动率。**

对于离散赌局（胜率 p，赔率 b）：
```
f* = (p·b − (1−p)) / b
```

### 为什么全 Kelly 在实务中不能用

| 原因 | 说明 |
|---|---|
| **参数估计误差** | μ 和 σ 是估计值。μ 高估 2 倍 → 杠杆高估 2 倍 → 可能进入负增长区 |
| 回撤极大 | 全 Kelly 的最大回撤期望在 50% 量级，几乎无人能承受 |
| 假设分布已知 | 厚尾会让实际最优杠杆远低于正态假设下的计算值 |
| 假设可连续调仓 | 离散调仓 + 跳空会带来额外损失 |
| 不考虑破产的效用 | Kelly 假设你能无限重复博弈，现实中归零就结束了 |

### 实务做法：分数 Kelly

```
实际仓位 = k × f*，其中 k ∈ [0.1, 0.5]
```

**推荐 k = 0.25 起步。** 理由：
- 半 Kelly 的期望增长率是全 Kelly 的 75%，但回撤只有一半
- 1/4 Kelly 的期望增长率约为全 Kelly 的 44%，回撤只有 1/4
- 考虑到 μ 的估计误差，实际最优 k 比理论值更低

**核心洞察：Kelly 曲线在最优点附近很平坦，但超过最优点后急剧下降。** 所以宁可保守到左边，绝不要冒险到右边。

### 我的用法

不直接用 Kelly 算仓位，而是：
1. 用 Kelly 计算"理论上限杠杆"，作为**绝对不能超过的红线**
2. 实际仓位用波动率目标法（下文），更稳健
3. 用 Kelly 提醒自己：**夏普低的策略不配高杠杆**

## 三、波动率目标法（推荐的主力方法）

### 逻辑

设定一个目标组合波动率，按预测波动率反向调整仓位：

```
仓位 = (目标波动率 / 预测波动率) × 信号强度
```

### 为什么它比 Kelly 实用

| 优点 | 说明 |
|---|---|
| **只需要估波动率，不需要估预期收益** | 波动率比收益率容易估得多（见 [`00-foundations/02-time-series.md`](../00-foundations/02-time-series.md)） |
| 自动降低高波动期的暴露 | 危机时自动减仓 |
| 让不同标的的风险贡献可比 | 天然的风险归一化 |
| 使收益分布更稳定 | 波动率更接近恒定，夏普通常提升 |
| 实证有效 | 大量研究显示 vol targeting 能改善风险调整后收益 |

### 实现要点

```python
# 概念示意
predicted_vol = ewma_vol(returns, halflife=20)      # 或 GARCH / HAR-RV
raw_position = signal / predicted_vol                # 信号按波动率标准化
scaled_position = target_vol * raw_position
final_position = clip(scaled_position, -max_pos, max_pos)   # 硬上限必须有
```

| 参数 | 建议 |
|---|---|
| 目标波动率 | 起步用较低值（如年化 15-20%）。crypto 里别用 40%+ |
| 波动率预测窗口 | 短窗口响应快但噪声大；长窗口滞后。用多窗口混合 |
| 调仓频率 | 太频繁 = 高换手成本；加一个"变化超过阈值才调"的死区 |
| 硬上限 | **必须有**，防止波动率估计失效时的极端仓位 |

### 失效场景（必须知道）

| 场景 | 问题 |
|---|---|
| 波动率骤升 | 预测滞后 → 你在高波动期还持着大仓位 |
| **波动率骤降后骤升** | 低波动期加大了仓位，然后波动跳升 → 放大亏损。这是 vol targeting 最危险的场景 |
| 跳空 | 波动率模型无法预测跳跃 |
| 低波动的假象 | 有些资产在崩盘前波动率很低（如脱锚前的稳定币） |

**对策**：加入"波动率上升时快速减仓、下降时缓慢加仓"的非对称调整。减仓要快，加仓要慢。

## 四、其他仓位方法

| 方法 | 说明 | 评价 |
|---|---|---|
| 固定金额 | 每笔固定 X USDT | 简单，但忽略风险差异 |
| 固定比例 | 每笔占总资金 X% | 有自动复利/去杠杆效果 |
| 固定风险 | 每笔风险（金额 × 止损距离）固定 | **实用**，把止损纳入了仓位计算 |
| ATR 法 | 用 ATR 定止损距离和仓位 | 波动率目标法的简化版 |
| 信号强度加权 | 信号越强仓位越大 | 与波动率目标结合使用 |
| **元标注输出映射** | ML 二级模型给出胜率 → 映射到仓位 | 见 [`04-ml-and-frontier/01-ml-for-finance.md`](../04-ml-and-frontier/01-ml-for-finance.md) |
| 反鞅（亏了加仓） | 马丁格尔类 | ❌ **绝对不用**，数学上保证爆仓 |

### 固定风险法值得单独说

```
仓位数量 = (账户风险金额) / (入场价 − 止损价)
```

好处：把止损距离和仓位统一了。止损远 → 仓位小；止损近 → 仓位大。每笔交易的最大损失固定。

**这是最容易执行、最不容易犯错的方法**，适合作为起步的默认方案。

## 五、杠杆的真实代价

### crypto 杠杆的隐藏成本

| 成本 | 说明 |
|---|---|
| 资金费 | 持仓成本，年化可达数十个百分点 |
| 借贷利率 | |
| **强平风险** | 不是"亏光"，是"在最糟的时刻被强制以最差价格平仓" |
| 阶梯保证金 | 仓位越大，允许杠杆越低（标称 100x 是营销，实际远低） |
| 波动率损耗 | 见上文的算术 |
| 心理成本 | 高杠杆下的浮亏会摧毁执行纪律 |

### 我的杠杆规则

```
阶段一（前 6 个月）：不加杠杆（gross ≤ 1.0）
阶段二（有 3 个月实盘数据后）：视策略类型考虑，且 gross ≤ 1.5
delta 中性套利：可以更高，但保证金充足率必须留大缓冲
方向性策略：长期不超过 2x
```

**为什么起步不加杠杆**：前期最大的风险不是"收益不够"，而是"系统有 bug"。bug + 杠杆 = 灾难。等系统跑稳了再谈效率。

## 六、多策略下的仓位分配

单策略仓位解决"这个策略下多少"，组合层解决"策略之间怎么分"。见 [`02-portfolio-construction.md`](./02-portfolio-construction.md)。

关键约束：**各策略仓位之和的风险，不等于风险之和**（有分散化效应），但也**不能假设分散化在极端情况下有效**。

保守做法：按"相关性 = 1"的假设检查总风险是否可承受。如果都同时亏，我能活下来吗？
